## 대화문
- **교사#28114 (교육과정·성취기준·EBS 연계형)**: 변형공학의 예시 창작은 **찬성**하되, **사실성 검증 체계**를 반드시 동반해야 한다.

구체적 구현 방법은 **1) 사실 기반 재구성(ZnO 나노입자 → "인공위성 소재"로 대체 시 NASA 기술 문서 참조)**, **2) AI-FACTCHECK 통합(예: 팩트체크 API나 GIGO(Google Fact Check Tools) API 연계)**, **3) 교차검증용 DB(예: 학술지 + 특허 DB) 구축**을 통해 허위 가능성을 차단하는 것이다.
- **교사#69350 (어휘·연어·서술형 채점 정밀형)**: 교사#28114의 사실성 검증 체계는 기술 문서나 DB 연계로 보완성 자체는 뛰어나지만, **"NASA 기술 문서"처럼 신뢰할 만한 출처조차 AI-FACTCHECK가 오판할 위험**이 있다. 특히 **특허 DB의 경우 기술 용어 중복·과장 표기**가 많아, AI가 이를 허위로 판단할 가능성도 무시할 수 없다. 결국 **FACTCHECK API의 종속성**을 어떻게 제어할지 명확한 프로토콜이 없으면, 변형공학 자체가 '검증된 오류'를 양산할 수 있다.
- **교사#16052 (언어학 이론·실용·상황형)**: **FACTCHECK API 종속성 문제**는 **다층 위계 검증**으로 해결한다. 1) **1차: AI-FACTCHECK(API)** → 2) **2차: 인간 교차검증(교과서/논문/특허 DB)** → 3) **3차: 전문가 패널(산·학·연)**로 단계적 승인을 거친 후 최종 반영하는 것이다. 특히 **특허 DB의 경우 '과장 표기'는 '용어 표준화 DB'(예: IPC 분류 기준)로 필터링하고, AI 오판 위험은 **‘불일치 스코어’(0~100%)로 표시**해 교사가 직접 판단토록 한다. 이 방식은 AI의 편향성을 줄이며, 변형공학의 신뢰성을 높이는 데 효과적이다.
- **교사#60220 (화용·함의·패러프레이즈 정교형)**: **보완 제안: "동적 출처 신뢰도 가중치 시스템"**

1차 AI-FACTCHECK는 **출처 신뢰도 점수(0~100%)**로 등급화(예: NASA 문서=95%, 특허 DB=70%)하고, **불일치 스코어**는 등급별로 차등 적용(높은 등급은 엄격, 낮은 등급은 관용적)로 오판을 최소화한다.

2차 인간 검증은 **‘교과서·논문·특허’ 간 상호 인용망 분석**을 추가해, **특허의 과장 표기를 IPC 분류가 아닌 ‘피인용 횟수’로 필터링**해 신뢰성을 객관화한다.

3차 전문가 패널은 **‘언어학적·기술적 이중 검증’**을 도입해, AI가 놓친 **문맥 오류(예: ‘인공위성 소재’로 ZnO 재구성 시 ‘우주 환경 내 내구성’ 같은 맥락 누락)**까지 감지토록 한다.
