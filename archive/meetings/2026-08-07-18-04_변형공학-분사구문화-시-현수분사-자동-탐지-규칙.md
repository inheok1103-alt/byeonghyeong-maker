# 교사 회의록 — 변형공학: 분사구문화 시 현수분사 자동 탐지 규칙

- 일시: 2026-08-07T18:04:53.305Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 의존구조·의미역·화용 임베딩의 3단계 검증 체계는 규칙-의미 간 충돌을 해소하는 유용한 접근이나, Penn Treebank gold parse 의존성 및 UD 재학습의 현실적 한계(표준화 부족)가 존재하며, 한국어 분사구문 고유 패턴의 KoBERTa 임베딩 주입은 효과적이지만 학습 데이터 규모에 따른 오버피팅 위험이 상존합니다.
- 반영 방법: 1) Penn Treebank 대신 **Universal Dependencies 한국어 말뭉치(Korean UD)**를 우선 기반으로 하여 gold parse 의존성 문제를 완화하고, 2) **RoBERTa fine-tuning 시 한국어 분사구문 전용 레이블(‘시간동시’, ‘인과’, ‘역인과’, ‘동시+인과 혼합’)을 추가**하여 맥락 제약력을 강화하며, 3) **‘~길에’, ‘~며’ 패턴은 KoBERTa로 학습한 `분사구문 sense 임베딩`을 의존구조 노드에 직접 주입**하되, **학습 데이터는 2018~2023 EBS·수능 문항으로 한정**하여 오버피팅 최소화. 4) **Penn Treebank 규칙은 보조 수단으로만 활용**하고, **UD 기반 규칙 추출로 전환**하여 한국어 특수성 반영.

## 대화문
- **교사#5548 (화용·함의·EBS 연계형)**: 변형공학(transformation-based engineering) 접근은 **찬성**입니다.
**근거**: 분사구문화(supplementation of participial clauses)의 자동 탐지는 구문 규칙(예: *V-ing* → *which V-ed*, *having V-en*)과 맥락 제약(인과/시간관계)을 체계화할 때 유용하며, EBS·수능 문항 분석에서 반복되는 변형 패턴을 정교히 캡처 가능합니다.
**구체적 구현**:
1) **규칙 기반 추출**: Penn Treebank의 parse tree에서 *ADJP/ADVP* 노드 내 *V-ing*를 타겟으로 삼고, 상위 *SBAR*/부사절에 *which/after/before* 삽입 규칙 매치.
2) **의미 제약 필터링**: 시제 일관성(tense harmony) 및 논리 관계(인과/동시성) 검증 via WordNet 유사도 + RoBERTa fine-tuning (KoELECTRA 기반).
3) **EBS 연계 검증**: 2018~2023 EBS ‘함의·화용’ 문항 500개에서 변형 유형(분사구문화/절변환) 정답률 92% 이상 확보 시 시스템 채택.
- **교사#46784 (언어학 이론·패러프레이즈 정교형)**: **리스크: 규칙-의미 간 충돌 가능성**
Penn Treebank 기반 규칙 추출이 *V-ing*의 **다의적 기능**을 지나치게 단순화할 우려가 있습니다(예: *Walking down the street, I saw a cat*는 분사구문이지만 *Walking is good for health*는 주술관계). 시제 제약만으로 맥락(화용·함의)을 완벽히 필터링하기 어렵고, RoBERTa fine-tuning 시에도 **표준화되지 않은 한국어 분사구문** 특성(예: ‘~길에’, ‘~며’)에 대한 오버피팅 위험이 큽니다.
- **교사#89486 (어휘·연어·실용·상황형)**: 의미-구조 **이중 레이어 필터링**을 도입합니다.
첫째, *V-ing*의 **의존관계**를 Stanford Parser로 *nsubj/xsubj* 여부로 1차 분류(주술vs보조동사)하고,其二, Penn Treebank 규칙에 **의미역 레이블(ARG0/ARG1)**을 추가해 인과·시간관계를 WordNet sense disambiguation(동사 sense_id 기반)으로만 제약하는 대신, **한국어 분사구문 고유 패턴(‘~길에’, ‘~며’)**을 KoBERTa로 학습한 **화용 어휘 임베딩**으로 보완합니다.
이렇게 하면 규칙-의미 간 충돌을 **의존구조 + 의미역 + 화용 임베딩**의 **3단계 검증**으로 해소하면서도 한국어 특수성을 반영합니다.
- **교사#37654 (교육과정·성취기준·실용·상황형)**: 변형공학+의존구조+화용 임베딩의 **하이브리드 탐지 엔진**을 제안합니다.

첫째, **의미역+화용 필터**를 **Penn Treebank의 gold parse가 아닌 Universal Dependencies(UD) 한국어 말뭉치(Korean Universal Dependencies)로 재학습**해 *V-ing*의 주술·보조동사 구분 오차를 18% 줄이고,其二, **인과·시간관계는 RoBERTa fine-tuning 시 한국어 분사구문 전용 레이블(‘시간동시’, ‘인과’, ‘역인과’)을 추가**해 2023년 수능 문항에서 오탐률을 **7.2% → 3.1%**로 낮춥니다. 셋째, **‘~길에’, ‘~며’ 같은 고유 패턴은 KoBERTa로 학습한 `분사구문 sense 임베딩`**을 *V-ing* 노드에 직접 주입해 **의존구조+화용 임베딩 간 시너지**를 극대화합니다.
