# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-17T17:49:02.526Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: compositional semantics 기반의 의미 보존 검증은 이론적 타당성이 있으나, 맥락 민감성(contextual sensitivity)과 화용론적 함축(pragmatic entailment)까지 포괄하는 체계가 필요하다는 교사#93828의 지적은 타당하다. 반면, 화용-의미 통합 검증 시스템을 설계하는 교사#40530과 교사#84698의 제안은 실용적 해법으로 평가된다.
- 반영 방법: 1) **의미 역할(Role Labeling) + 사건구조(Event Structure) 매핑**을 기본으로 삼되, 2) **다층적 논리형식(MLF)**에 **화용론적 함축(pragmatic entailment)**을 제3층으로 編入하여 ‘kill vs. cause-to-die’와 같은 미묘한 의미 변화를 정량적 자동화로 포착. 3) **의존성 기반 패턴 DB**를 활용해 사건 변환 오류( event transformation error )를 탐지하고, 4) **이중 조건부 파이프라인**으로 Tarski truth-conditions와 화용론적 조건을 동시 검증하는 **4단계 통합 시스템**으로 개선.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학의 의미 보존 자동 검증은 **찬성** 입장이다. **근거**: 언어학적 의미론(compositional semantics·event semantics)에서 어휘-구문 변환은 의미 결합 규칙에 의해 보존 가능하며, 기계적 정합성(consistency) 검증이 가능하다는 이론적 타당성이 존재한다. **구체적 구현 방법**:
1) **의미 역할(Role Labeling)** + **구문-의미 인터페이스(Semantic Role Labeling + AMR)**로 변환 전후 의미구조를 매핑하고,
2) **논리형식(Logic Form)** 비교(λ-calculus 동등성·Tarski truth-conditions)로 의미 동일성 검증,
3) **의존성 기반 오류 패턴 DB**(e.g., 의존성 구조 왜곡·논리연산자 오류)를 구축해 자동 탐지하는 **3단계 파이프라인**을 적용하면 된다.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: Compositional semantics 기반 접근은 **맥락 민감성(contextual sensitivity)**을 과소평가합니다. λ-calculus 동등성으로 검증하려면 **암시적 의미(implicature)**나 **화용론적 함축(pragmatic entailment)**까지 포괄해야 하는데, 이는 정량화·자동화에 한계가 있습니다. 특히 **사건 구조(event structure)**가 변환 과정에서 손상될 경우, truth-conditions만으로는 미묘한 의미 변화(예: ‘kill vs. cause-to-die’)를 잡아내기 어렵습니다.
- **교사#40530 (듣기·구어체·실용·상황형)**: 변형공학의 의미 보존 자동 검증은 **의미 역할(Role Labeling) + 논리형식(Logic Form) 비교**에 **화용론적 맥락 필터링(Pragmatic Context Filtering)**을 **선제적**으로 추가해야 한다. 구체적으로:

1) **이벤트 구조(event structure)** 손상 여부를 **의존성 기반 패턴 DB**에서 **장면( scena )·역할( role )·결과( result )**의 삼중구조로 분석하고,
2) **화용론적 함축(pragmatic entailment)**을 **대화’act( speech act )·전제(pre-supposition)·함축(implicature)**로 분류해 **다층적 논리형식(MLF: Multi-Layered Logic Form)**으로 변환·비교하며,
3) **사건 변환 오류( event transformation error )** 발생 시 **Tarski truth-conditions**과 **화용론적 조건(pragmatic conditions)**을 **동시 검증**하는 **이중 조건부 파이프라인(pipeline)**을 적용해야 한다.

이 방식은 compositional semantics의 이론적 견고성과 맥락 민감성을 **양립**시키는 실용적 해법이다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: 변형공학의 의미 보존 자동 검증은 **의미역할(Role Labeling) + 사건구조(Event Structure) 매핑 + 다층적 논리형식(MLF)**을 기반으로 **화용-의미 통합 검증** 시스템을 설계해야 한다. **Tarski truth-conditions**과 **화용론적 함축(pragmatic entailment)**을 **동시 검증**하는 **이중 조건부 파이프라인**에 **의존성 기반 패턴 DB**를 결합해, compositional semantics의 이론적 견고성과 맥락 민감성을 **실행 가능한 수준**에서 양립시킨다. 특히 **암시적 의미(implicature)**와 **전제(pre-supposition)**를 **논리형식의 제3층**으로 編入해, ‘kill vs. cause-to-die’ 같은 미묘한 의미 변화를 **정량적 자동화**로 잡아낼 수 있도록 구조화해야 한다.
