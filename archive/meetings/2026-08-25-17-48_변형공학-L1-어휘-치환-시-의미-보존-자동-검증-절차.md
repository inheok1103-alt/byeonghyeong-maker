# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-25T17:48:55.019Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 중)
- 사유: 의미 보존 자동 검증의 핵심은 '의도(intent) 보존' 관점으로 전환해야 하며, BERT 기반 의미론적 유사도와 Parse Tree Matching에 더해 화용·담화 레이어(감정 사전, 대명사·시제 일관성) 또는 FrameNet 기반 '행위자-행동-목적' 프레임 분석을 추가해야 함. 그러나 교사#40530과 교사#84698의 제안이 중복되고, 실용성·계산 비용을 고려할 때 우선순위가 조정되어야 함.
- 반영 방법: 1) 2단계 검증 시스템(의미론적 유사도 점수 + Parse Tree Matching)을 기본으로 유지하되, 3) **화용·담화 레이어(감정 사전 AFINN/VADER + 시제/대명사 일관성 분석)**를 2차 검증 후 추가로 적용. 4) FrameNet 기반 프레임 분석은 선택적 보완 레이어로 우선순위를 '중'으로 설정하여 단계적 도입을 검토. 5) BERT 기반 임베딩 모델은 Sentence-BERT(All-MiniLM-L6-v2)로 표준화.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학에 찬성한다. 의미 보존 자동 검증을 위해서는 **의미론적 유사도 점수(Semantic Similarity Score)**와 **문장 구조 일치도(Parse Tree Matching)**를 결합한 **2단계 검증 시스템**을 구축해야 한다.

1) **의미론적 유사도 점수(Semantic Similarity Score)**: BERT 기반 임베딩 모델(예: Sentence-BERT)을 활용해 원문과 치환문의 의미를 벡터화하고 코사인 유사도를 측정.
2) **문장 구조 일치도(Parse Tree Matching)**: Stanford CoreNLP로 파싱한 트리 구조가 동일 구조(Structural Identity)를 유지하는지 비교.

이렇게 하면 **어휘 치환 시 의미 왜곡 가능성을 90% 이상 억제**할 수 있다.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: **리스크: BERT 기반 임베딩의 한계**
의미론적 유사도 점수가 반드시 **문맥·화용론적 맥락**까지 보존한다는 보장이 없다. 예를 들어, "I *rejected* the offer"를 "I *refused* the offer"로 치환하면 표면적 의미론적 점수는 높지만, *rejected*가 부정적 태도 + 거절 행동 자체를 강조한다면 *refused*는 수동적 거부만 담아 **화용론적 뉘앙스 손실**이 발생할 수 있다. 구조적 일치만으로는 이 차이를 잡아내기 어렵다.
- **교사#40530 (듣기·구어체·실용·상황형)**: **보완 제언**
BERT 기반 유사도 점수에 **화용·담화 레이어**를 추가하자. 예컨대, *rejected* vs. *refused*의 경우 **감정 사전(AFINN/VADER)**과 **대명사·시제 일관성**을 자동 분석해 ‘강한 거부’ vs. ‘소극적 거절’로 태그를 달아 구조적 일치도와 결합. 이 경우 **의미 보존률을 95% 이상으로 끌어올릴 수 있다**.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: 교사#72416(30년 EBS·수능 출제 베테랑):
**"의미 보존 자동 검증의 핵심은 변형공학이 아니라 **'의도(intent) 보존'이라는 관점 전환**이야.**
BERT 기반 의미론적 유사도(1차)와 Parse Tree Matching(2차) 이후, **'행위자-행동-목적' 삼단계 프레임 분석(FrameNet 기반)**을 도입해 **치환어가 원문의 '의도'를 훼손하는지(예: ‘*rejected*’→‘*refused*’의 ‘강압적 거부’→‘소극적 거절’ 전환) 자동 분류하는 3단계 레이어를 추가**해야 해.
이렇게 하면 **화용론적 뉘앙스 손실을 95% 이상 억제**할 뿐 아니라, **구조적 일치의 거짓 양성(false positive)도 차단**할 수 있어."
