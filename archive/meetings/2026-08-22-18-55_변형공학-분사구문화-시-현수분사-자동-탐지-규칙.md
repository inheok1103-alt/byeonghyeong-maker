# 교사 회의록 — 변형공학: 분사구문화 시 현수분사 자동 탐지 규칙

- 일시: 2026-08-22T18:55:07.776Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 의미역 레이블링(SRL)의 오류 전파 문제를 해결하기 위한 '의미역-구조 상호검증(SRL-Structure Cross-Verification)' 프레임워크가 실용성과 이론적 타당성을 인정받았으나, 모든 구성 요소(예: 의미그래프 기반 검증)가 즉시 구현 가능한지는 검토가 필요함. 또한, 하이브리드 시스템의 기본 틀은 유지하되, SRL 오류 전파 방지를 위한 보완 메커니즘을 구체화해야 함.
- 반영 방법: 1) 규칙 기반 패턴 매칭(Rule-based Pattern Matching)으로 분사구문 후보군을 선별한 후, 2) KoELECTRA Fine-tuning을 통해 초기 모델을 학습하고, 3) '의미역-구조 상호검증' 프레임워크를 도입하여 SRL 출력+의미역-구조 제약(Constraint-based SRL Re-ranking)과 경량 의미그래프(Semantic Graph Pruning)를 적용. 4) 최종적으로 '의미역 신뢰성 지표(SRL Reliability Score)'를 도입해 모델 신뢰성을 평가.

## 대화문
- **교사#5548 (화용·함의·EBS 연계형)**: 변형공학(transformation-based engineering) 자체는 유용한 접근법이지만, **분사구문화(paticipial construction) 현수분사 dangling modifier 자동 탐지 규칙**에는 한계가 명확합니다.

**근거**: 문법 규칙의 복잡성과 문맥 의존성(예: 생략된 주어 복원) 때문에 규칙 기반 접근만으로는 높은 정확도를 기대하기 어렵습니다. **구체적 구현 방법**으로는 우선 **규칙 패턴 매칭(Rule-based Pattern Matching)**으로 후보군을 선별한 후, **의미역 레이블링(Semantic Role Labeling)**이나 **전이 학습(Transfer Learning)** 기반 모델(예: KoELECTRA)을Fine-tuning하여 정밀도를 높이는 **하이브리드 시스템**이 현실적입니다.
- **교사#46784 (언어학 이론·패러프레이즈 정교형)**: **"하이브리드 시스템도 문맥 의존성 문제를 완화할 순 있어도, **의미역 레이블링(SRL)의 오류 전파**가 정밀도에 치명적 영향을 미칠 우려가 있다."**
예: "After completing the experiment, the results were analyzed"에서 SRL이 "results"를 주어(AGENT)로 잘못 태깅하면 모델이 오류를 학습할 수밖에 없다.
- **교사#89486 (어휘·연어·실용·상황형)**: **"의미역 레이블링(SRL)의 오류 전파 문제를 보완하려면, **의미역 레이블링과 병행하여 **의미적 일관성 검증(SEM-Consistency Check)**을 도입**하는 것이 효과적입니다. 예컨대, *‘After completing the experiment’*의 경우, ‘completing’의 의미역이 실험(*AGENT*)이 아닌 실험자(*EXPERIENCER*)로 복원되는지 **의미ネットワーク 기반으로 검증**하거나, **대용어 해결(Anaphora Resolution)**을 통해 생략된 주어(*‘the researcher’*)를 명시적으로 복원한 후 규칙을 적용하는 방식입니다. 이렇게 하면 SRL 오류가 발생해도 **의미적 모순 여부를 사전 필터링**할 수 있어 정밀도가 향상됩니다.**
- **교사#37654 (교육과정·성취기준·실용·상황형)**: **의제 제안: "의미역 레이블링(SRL) 오류 전파 문제를 해결하는 **‘의미역-구조 상호검증(SRL-Structure Cross-Verification)’** 프레임워크 도입**
1) **SRL 출력+의미역-구조 제약(Constraint-based SRL Re-ranking)**: KoELECTRA Fine-tuning 시, 문법 트리(예: constituency/dependency parse)와 SRL 레이블 간의 **형태-의미 제약**을 강제하는 사후 필터링 층을 추가(예: "results"가 *THEME*이 아닌 *EXPERIENCER*로 태깅되면 후처리 거부).
2) **경량 의미그래프(Semantic Graph Pruning)**: 의미역 후보군을 시맨틱 그래프(예: *WordNet/ConceptNet*)로 변환해 통사적/의미적 모순(예: *AGENT*가 비인간 명사일 경우)을 실시간 배제하는 **실행 가능성 체크(Feasibility Check)** 시스템 도입.

*이 프레임워크는 규칙 기반 탐지와 하이브리드 모델 간의 간극을 메우는 **‘의미역 신뢰성 지표(SRL Reliability Score)’**로도 활용 가능.*
