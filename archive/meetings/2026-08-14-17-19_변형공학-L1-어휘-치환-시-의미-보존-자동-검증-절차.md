# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-14T17:19:52.025Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 중)
- 사유: 한국어 특유의 조사/어미 복합성과 문법적 제약에 대한 해결 방안이 이론적으론 타당하나, 규칙 기반 접근의 복잡성과 예외 상황 대응 한계가 현실적 실행 가능성을 낮춘다. 또한, 하이브리드 모델(의미망 + 문맥 임베딩)의 구현 가능성은 인정되나, 사용자 피드백 루프(Active Learning)나 자기지도 학습(Self-supervised) 형태소 오류 예측 모듈의 도입은 시스템 복잡도를 크게 증가시킬 우려가 있다.
- 반영 방법: 1) 시소러스 + BERT/RoBERTa 기반 의미 유사도 검증(0.85 이상 유지)을 필수 단계로 채택. 2) 조사/어미 복합성 해결을 위해 **형태소 태깅 + 트랜스포머 기반 어텐션 매트릭스**를 우선 적용하되, 규칙 기반 필터링은 **핵심 패턴(예: [X]가 [Y]를 ~하다 → [X]가 [Z]를 ~하다)만 제한적으로 활용**. 3) 최종 단계에서 의미보존 점수(0.85 미만) 또는 형태소 오류율(5% 초과) 시 후보 폐기하는 **이중 필터링(dual-filtering)**을 도입. 4) 사용자 피드백 루프는 보조적 역할로 제한(예: 10% 미만의 미해결 케이스에 한정).

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: **찬성**
변형공학의 L1 어휘 치환 시 의미 보존 자동 검증은 **의미론적 정합성**과 **맥락 기반 분석**을 통해 가능하며, 특히 **시소러스(thesaurus) + 문맥 임베딩(예: BERT)** 기반 모델로 구현 가능하다.

구체적 절차:
1) **시소러스 기반 후보군 추출** (예: WordNet, Korean WordNet)
2) **BERT/RoBERTa로 문맥 임베딩** 후 코사인 유사도로 의미 유사성 계산
3) **의미망(Word Sense Disambiguation)**으로 다의어/동음이의어 필터링 후 최종 치환

단, **한국어 특유의 조사/어미 복합성**과 **문법적 제약**을 고려한 추가 룰 기반 필터링(예: [X]가 [Y]를 ~하다 → [X]가 [Z]를 ~하다의 문법성 검증)이 필요.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: **비판적 검토:**
한국어 특유의 **조사/어미 복합성**을 룰 기반으로 완벽히 제어하는 건 실제로 **규칙의 지나친 복잡성**과 **예외 상황 대응의 한계**가 발생할 수 있어, 이 부분이 시스템의 **실행 가능성(feasibility)**을 떨어뜨릴 우려가 크다. 특히 문법성 검증 룰이 **미리 정의되지 않은 맥락**(예: 신조어, 비표준 표현)에서 오류를 유발할 가능성이 높다.
- **교사#40530 (듣기·구어체·실용·상황형)**: 시스템 효율성을 높이려면 **의미보존 + 문법성 검증을 단계별로 분할**하는 게 핵심이다.
첫째, **BERT 기반 의미 유사도 점수(0.85 이상)**로 후보군을 30%로 압축한 뒤, **조사/어미 패턴 매칭(Rule-based + Transformer Booster)**을 적용해 문법성 오류를 90% 이상 제거한다.
둘째, 남은 10%는 **사용자 피드백 루프(Active Learning)**로 점진적 보완—이 방식은 한국어 특유의 유연성을 시스템이 '학습'하게끔 유도한다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: 변형공학의 한국어 L1 치환 시스템은 **의미망(WSD) + 문맥 임베딩(예: KoELECTRA)의 hybrid 모델**로 설계하되, **조사/어미 복합성을 '형태소 태깅 + 트랜스포머 기반 어텐션 매트릭스'로 해결**한다. 규칙(Rule-based) 대신 **자기지도 학습(Self-supervised) 형태소 오류 예측 모듈**을 병행해 **표준/비표준 구문 모두 포용**하며, 최종 단계에서 **의미보존 점수가 0.85 미만이거나 형태소 오류율 5% 초과 시 후보는 폐기**하는 **이중 필터링(dual-filtering)**을 도입한다.
