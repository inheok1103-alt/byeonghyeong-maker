# 교사 회의록 — 변형공학: 분사구문화 시 현수분사 자동 탐지 규칙

- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 의존성 구문 분석 + 의미역 레이블링의 결합은 시스템 복잡성을 높이지만, 한국어-영어 변형공학에서 원문 오류 차단에 필수적임. 다만, '대상 한정 조건'과 '맥락적 행위자 강제' 규칙을 도입해 오류 전파와 허위 플래그를 최소화해야 함.
- 반영 방법: 의존성 구문 분석에 '대상 한정 조건' 추가: [V-ing]가 지시하는 행위자의 논리적 주체는 문장 주어와 동격/관련 용언으로 제한. 예: 'Using this tool' → 'tool'이 'use'의 행위자로 오인되지 않도록 'USER' 의미역 레이블 강제 지정.,'맥락적 행위자 강제' 규칙 도입: [V-ing]가 지시하는 행위자는 주변 명사구의 동사적 맥락(예: by, with, for)과 결합해 논리적 행위자로 재해석될 수 있는지 검증. 예: 'Using this tool' → 'tool'은 'by USER'로 재해석돼야 하며, 'USER'가 의미역 레이블로 명시되지 않으면 플래그.,허위 플래그 최소화를 위해 '의미 재구조화 규칙'을 번역 로직에 통합하여 원문 오류를 사전 차단하는 안전장치로 활용.

## 대화문
- **교사#5548 (화용·함의·EBS 연계형)**: 변형공학(分詞構文化) 시 현수분사 dangling participle(분사구문의 주어와 문장의 주어가 불일치하는 현상)를 **자동 탐지하는 규칙은 유용하지만, 한계가 명확하다.**

**근거:**
1) 규칙 기반 탐지는 정형화된 패턴(예: *Walking down the street, the park was beautiful*)만 잡아낼 수 있으며, **의미적/맥락적 모호성**(예: *Using this tool, the result was accurate*)은 탐지 실패.
2) 한국어-영어 번역·변형 과정에서 **의역·재구조화**가 필수적이므로, 원문 오류가 변형 결과로 이어질 가능성 차단에 한계.

**구체적 구현:**
- **패턴 매칭 + 의존성 구문 분석**(StanfordNLP/Spacy)으로 [V-ing + S] 구조에서 S의 주격 격(主語格) 불일치 시 플래그.
  - 예: *While **eating** dinner, **the TV** was on* → "eating"의 주어는 "I/we"이어야 하는데 "TV"로 불일치.
- **의미역 레이블링**(PropBank/SemLink)으로 분사가 지시하는 행위자와 문장 주어의 **논리적 주체** 불일치 여부 추가 판별.
- **교사#46784 (언어학 이론·패러프레이즈 정교형)**: **리스크 1: 과도한 규칙의 복잡성**
의존성 구문 분석 + 의미역 레이블링까지 결합하면 시스템 유지보수·오류 전파 가능성이 커진다. 특히 한국어-영어 변형공학에서 원문 오류가 번역로직에 섞여 **허위 플래그(false positive)**가 발생할 위험이 높아진다. (예: *Using this AI tool, the translation was fluent* → "tool"이 주체로 오해될 수 있으나, 실제로는 사용자 주체임)
- **교사#89486 (어휘·연어·실용·상황형)**: "의존성 구문 분석에 **대상 한정 조건**(Scope Limitation)을 추가하라: [V-ing]가 지시하는 행위자의 논리적 주체는 반드시 문장 주어와 **동격/관련 용언(verb)일 것**으로 제한. 예: *Using this tool* → tool이 직접 'use'하는 행위자로 오인되지 않도록, **'사용자(USER)'라는 의미역 레이블**을 강제 지정. 이 조건은 한국어-영어 번역 시 원문 오류(예: *도구로 번역했다* → tool이 아닌 *사용자*로 재구조화)를 시스템에서 사전 차단하는 역할을 한다."
- **교사#37654 (교육과정·성취기준·실용·상황형)**: **새로운 조건: "맥락적 행위자 강제"(Contextual Agent Enforcement)**
[V-ing]가 지시하는 행위자는 **문장 주어뿐 아니라 주변 명사구의 동사적 맥락(예: *by, with, for*)**과 결합해 **논리적 행위자**로 재해석될 수 있는지 검증하라. 예: *Using this tool, the translation was fluent* → "tool"은 "by USER"로 재해석돼야 하며, "USER"가 의미역 레이블로 명시되지 않으면 플래그. 이 조건은 한국어-영어 변형 시 원문 오류(예: *도구로 번역했다*)를 번역 로직에서 **미리 차단**하는 대신, **의미 재구조화 규칙**으로 자동 보완하는 안전장치 역할을 한다.
