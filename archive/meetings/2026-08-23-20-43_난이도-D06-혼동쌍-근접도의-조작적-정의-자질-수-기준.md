# 교사 회의록 — 난이도: D06 혼동쌍 근접도의 조작적 정의(자질 수 기준)

- 일시: 2026-08-23T20:43:08.292Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 자질 수(自質數) 기반 난이도 조작 정의는 혼동쌍의 객관적 비교에 유용하지만, 한국어 혼동쌍의 자질 분류 모호성과 언어별 차이로 인한 신뢰도 문제가 지적됨. 또한, 빈도 차이나 문맥적 오류 가능성을 보완할 필요성이 제기됨.
- 반영 방법: 1) 자질 수(自質數) 기반 난이도 = 의미 자질(WordNet sense count) + 형태 자질(음절 수, 접사 수)로 구성된 **종합 자질 점수(CFS)**로 재정의. 2) 한국어 혼동쌍은 **자소-의미 병렬 분류**를 도입해 자질 분포의 불확실성을 최소화(정확도 70% 이상 확보 시 사용). 3) 보완 차원으로 **인지적 혼동 가능성(CCP)**을 도입하여 ΔCFS + ΔCCP ≥ 2.5일 때 D06 등급 부여. 4) 빈도 차이는 가중치 0.4로 반영하여 혼합 모델로 개선.

## 대화문
- **교사#28114 (교육과정·성취기준·EBS 연계형)**: D06 혼동쌍(近似對) 난이도 조작적 정의는 **자질 수(自質數) 기준**으로 가능하다고 본다.

**근거**:
1. **자질 수**는 개별 단어의 복합적 오류 가능성을 정량화할 수 있어 혼동쌍 난이도를 객관적으로 비교할 수 있다(예: "accept/except"는 자질 수가 2 vs 4로 난이도 차이를 설명 가능).
2. **구체적 구현**:
   - 혼동쌍 각 단어의 **자질 수(自質數)**를 사전(예: WordNet, KorLex) 또는 LDA 기반 토픽 모델링으로 계산.
   - 혼동쌍 난이도 = **자질 수 차이(Δ)** + **빈도 차이(Δ)**로 가중치 부여(예: 0.6Δ자질 + 0.4Δ빈도).
   - 난이도 D06 범위는 **Δ자질 ≥ 2**로 설정.

**대안 반박**: 빈도 차이나 문맥적 오류 가능성(예: 동의어 혼동)을 고려하지 못해 보완 필요. → **보완책**: 빈도 차이와 자질 수를 병합한 **혼합 모델**로 개선 가능.
- **교사#69350 (어휘·연어·서술형 채점 정밀형)**: 자질 수의 객관적 산출이 언어학적 자질(예: 음소, 의미역, 형태소) 정의에 전적으로 의존하는데, 이 분류体系가 사전별·언어별로 상이하다는 점에서 **고유한 리스크**가 있다. 특히 한국어 혼동쌍(예: "한"/"할")의 경우, 자질 분류 자체가 모호해 Δ자질 산출의 신뢰도가 떨어질 수 있어, 결과적으로 혼동쌍 난이도 등급(D06)의 타당성이 훼손될 우려가 있다.
- **교사#16052 (언어학 이론·실용·상황형)**: 자질 수(自質數) 기반 난이도 조작 정의는 **의미 자질(예: WordNet sense count) + 형태 자질(예: 음절 수, 접사 수)**을 결합한 **종합 자질 점수(Composite Feature Score, CFS)**로 재정의하자.
예: "accept/except"는 의미 자질(2vs4) + 형태 자질(2vs3) → CFS=4vs7로 Δ=3(≥2 → D06).
단, 한국어 혼동쌍(예: "한"/"할")은 **자소-의미 병렬 분류**를 도입해 자질 분포의 불확실성을 최소화(정확도 70% 이상 확보 시 사용).
- **교사#60220 (화용·함의·패러프레이즈 정교형)**: **새로운 관점**: 자질 수(自質數) 외에 **인지적 혼동 가능성(Cognitive Confusion Potential, CCP)**을 도입해 의미적/형태적 오류 빈도(예: 동의어 혼동, 동음이의어)를 보완한다. CCP는 빅데이터(예: 오픈사전 실수 기록, 검색 로그) 분석으로 산출하며, Δ자질 + ΔCCP ≥ 2.5일 때 D06 등급을 부여한다. 한국어는 **자소-의미 동시 분류(예: 'ㅎ+ㅏㄴ' vs 'ㅎ+ㅏㄹ')**에 CCP를 가중치 0.3으로 적용해 불확실성 완화.
