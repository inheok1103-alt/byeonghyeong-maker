# 교사 회의록 — 변형공학: 예시 교체 창작 시 사실성 검증(허위 정보 방지)

- 일시: 2026-07-25T19:37:24.996Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 변형공학의 예시 창작은 학생의 창의적 사고력과 문제 해결력을 제고하는 데 유용하나, 허위 정보나 사실 왜곡의 위험이 상존한다. 검증 체계의 부재는 수능·내신의 신뢰도 저하로 이어질 수 있으므로, 엄격한 사실성 검증 프로토콜이 필수적이다.
- 반영 방법: 1) ‘3층 검증 체계’(학술 DB·표준 교과서·기출문제 → AI 문서 분석·전문가 리뷰 → 난이도 조정)를 적용해 사실성·최신성·난이도 균형을 유지. 2) ‘AI 기반 사실성 엔진’(학술 DB + 정부 보고서 + 최신 논문 API 연동)과 ‘블랙리스트 자동 갱신’을 통한 실시간 검증 시스템 구축. 3) 교과서·EBS·기출문헌 기반 ‘사실성 체크리스트’(출처·맥락·난이도)를 표준화하여 예시 변형 시 필수 적용.

## 대화문
- **교사#28114 (교육과정·성취기준·EBS 연계형)**: 변형공학의 예시 교체 창작은 **찬성**한다. 이유는 **수능·내신 출제 원칙(사실성·맥락 일치·난이도 균형)**을 유지하면서도, 학생의 **창의적 사고력·문제 해결력**을 끌어낼 수 있기 때문이다. 구체적 구현 방법은 **교과서·EBS·기출문헌(예: NE능률, 능률교육) 기반의 ‘사실성 체크리스트’(출처·맥락·난이도)를 적용**해, 허위 정보 없이 예시를 변형·보완하는 것이다. (예: ‘과학기술’ 주제에서 **‘AI 진단’ → ‘인공지능 암 진단 알고리즘’**으로 사실성·최신성 높임)
- **교사#69350 (어휘·연어·서술형 채점 정밀형)**: 변형공학의 예시 교체 창작은 **사실성 검증 체계가 부재할 경우**, 학생들이 **과도한 상상력**에 기대어 **사실 왜곡**이나 **과장된 맥락**을 문제로 삼을 가능성이 크다.
예를 들어, "AI 진단"을 "인공지능 암 진단 알고리즘"으로 변형할 때, **최신 연구 동향(2023년 기준 AI4HC 등)**을 반영하지 못해 **과거 지명도 높은 기술**로 대체하거나, **허위 인용**을 유도할 수 있다.
이는 **수능·내신의 신뢰도 하락**으로 이어질 수 있으므로, **검증 프로토콜(예: 전문가 리뷰·학술 DB 크로스체크)**이 필수다.
- **교사#16052 (언어학 이론·실용·상황형)**: 변형공학의 예시 창작은 **‘사실성 + 최신성 + 난이도 균형’을 동시에 충족하는 ‘3층 검증 체계’**로 설계해야 한다.
첫째, **학술 DB(DBpia, KCI 등)·표준 교과서·기출문제**를 **1차 출처 삼아 출처 명시성·맥락 일치성을 점검**하고,
둘째, **2차로 AI 문서 분석(Ex: 2023~2024년 최신 논문·정부 보고서)이나 교과서 저자/감수자 리뷰**를 통해 **과학적·언어적 오류를 예방**하며,
셋째, **난이도 조정(예: ‘AI 암 진단 알고리즘’ → ‘AI 기반 조기 진단 모델’로 난이도 하향 조정 가능성 검토)**을 통해 **수준별 맞춤형 변형**을 구현해야 한다.
- **교사#60220 (화용·함의·패러프레이즈 정교형)**: 변형공학의 예시 창작은 **‘3차원 검증 + 동적 업데이트 시스템’을 도입**해야 한다.
첫째, **출처·맥락·난이도**를 실시간 크로스체크하는 **‘AI 기반 사실성 엔진’**(예: 학술 DB + 정부 보고서 + 최신 논문 API 연동)이 필요하며,
둘째, **학생·교사·전문가 간 피드백 루프**를 통해 **허위/과장된 예시가 발견 즉시 차단**하는 **‘블랙리스트 자동 갱신’**을 구축해야 한다.
이 방식은 **창의성 제고와 신뢰성 유지의 균형**을 객관적으로 제어할 수 있다.
