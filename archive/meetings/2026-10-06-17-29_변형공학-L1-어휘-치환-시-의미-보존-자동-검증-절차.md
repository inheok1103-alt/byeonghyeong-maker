# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-10-06T17:29:56.745Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: BERT 기반 유사도 검증은 유용하지만, 은유·비표준 표현 등에서 오차가 발생할 위험이 있어 다중 검증과 학습 단계별 가중치를 도입해 정확성을 높이자.
- 반영 방법: 1) BERT cosine‑similarity를 기본 필터로 사용하되, 0.7–0.85 구간은 자동 승인 대신 교사 검토 트리거. 2) 의존구문 분석을 추가해 주어‑동사‑목적어 구조가 유지되는지 확인. 3) ‘의미 변형 위험군’에 해당하는 문장은 AI 점수를 낮추고 최종 승인 전 인적 검토 필수. 4) 학습 목표에 따라 가중치 부여(기초: 0.7–0.8 자동 승인, 전공: 0.8–0.9 자동 승인). 5) 과거 오류 이력 기반 동적 필터링으로 자주 오류가 발생한 치환어를 차단.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: **찬성**.  
- **근거**: L1 어휘 치환 시 의미 보존을 자동으로 검증하면 교재·시험 문제 제작 시 오역을 줄이고, 학습자의 이해도를 높일 수 있다.  
- **구체적 구현 방법**: LLM 기반 의미 유사도 모델(예: BERT)으로 후보 치환어와 원문 문장을 비교, cosine‑similarity > 0.85이면 의미 보존된 것으로 판단하고, 0.7–0.85 구간은 교사 검토를 거치도록 하여 정확성을 확보한다.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: 우려: BERT 같은 모델은 문맥이 복잡하거나 은유·말장난 같은 비표준적 표현에 대해 의미를 잘 잡아내지 못해, ‘cosine‑similarity > 0.85’ 기준을 무조건 적용하면 실제로 의미가 변형된 문장을 잘못 승인할 위험이 있다. 이는 교재·시험에서 학생들의 오해를 초래할 수 있다.
- **교사#40530 (듣기·구어체·실용·상황형)**: 다중 체크 방식을 도입해 보자: 문맥‑유사도 외에 **의존구문 분석**을 통해 핵심 구문(주어‑동사‑목적어)와 어휘의 역할이 그대로 유지되는지 확인하고, 의미 변형이 의심되는 경우에만 교사 검토를 트리거한다. 또한 은유·비표준 표현이 포함된 문장은 사전 등록된 “의미 변형 위험군”에 자동으로 분류해 인공지능 평가지표를 낮추고, 최종 승인 전 사람이 직접 검토하도록 한다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: 이외에 **학습 목표에 따른 가중치 부여**를 도입하면 좋겠어. 예컨대 ‘어휘 선정이 기초 수준’이라면 0.7‑0.8 구간을 자동 승인, ‘전공·전문 용어’라면 0.8‑0.9 구간을 자동 승인하도록, 의미 보존 기준을 학습 단계별로 차등 적용해 보자. 또한, **오류 이력 데이터**를 활용해 과거에 오류가 발생한 치환어를 자동 차단 목록에 넣는 동적 필터링 기능을 추가하면 실시간 검증 정확도를 한층 끌어올릴 수 있어.
