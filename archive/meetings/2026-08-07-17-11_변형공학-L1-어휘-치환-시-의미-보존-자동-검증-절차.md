# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-07T17:11:37.708Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 의미 보존 자동 검증 절차의 핵심 틀(의미역·구문구조 보존 + FOL 모델 체킹 + NLI 기반 맥락 검증)은 공통적으로 인정되나, 화용론적 뉘앙스·은유·문화적 함의 등 출제 원칙상 엄격한 ‘의미 변별성’을 위협하는 요소에 대한 보완이 필요하다는 점에서 교사#40530과 #84698의 제안이 보완적으로 수용되어야 함.
- 반영 방법: 1) **STEP 1**: 의미역(θ-roles) + 구문구조(PS-트리) 보존에 **의미역 범위(θ-grid) 확장**을 추가하여 PropBank 범주형 오류(예: '과시' 뉘앙스)를 논리적 계층(θ-subtype)으로 필터링. 2) **STEP 3**: NLI 모델(예: RoBERTa-NLI) + 감정·화용 임베딩(예: VADER, Polarity Score)을 결합한 **다층 검증(AND 조건)**으로 화용론적 위반을 보수적으로 검증. 3) **MPG(의미 보존 다면성 등급제) 도입**: Level 1(논리적 동등성) + Level 2(맥락 등가성, EBS·수능 ‘맥락별 어휘 선호도 DB’ 기반 CEA) + Level 3(화용·담화 일관성, PPKG 기반 문화적 함의 필터링)으로 등급화하고, 각 단계 통과 시 ‘출제 가능성 점수(MPS)’를 부여하여 출제 원칙과의 괴리 해소.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학의 **의미 보존 자동 검증**은 **찬성**한다. **① 언어학적 의미론(compositional semantics) 기반 자동 검증을 통해 보편적 의미 보존 규칙(예: FOL 변환 + 모델 체킹)을 적용**하고, **② EBS·수능 출제 원칙(의미 변별성, 맥락 일관성)에서 필수적인 ‘논리적 동등성’을 기계적으로 검증**할 수 있기 때문이다. **구체적 구현**:
- **STEP 1**: L1 어휘를 **의미역(θ-roles) + 구문구조(PS-트리) 보존**으로 치환(예: "He runs" → "He sprints" via WordNet synset + PropBank frame 매핑).
- **STEP 2**: **FOL(1차술어논리)로 변환**한 뒤, **BDD(이진결정다이어그램) 기반 모델 체킹**으로 의미 동등성 검증(예: ∀x.(run(x) ↔ sprint(x))).
- **STEP 3**: **맥락 임베딩(예: Sentence-BERT) + NLI 모델(예: RoBERTa-NLI)**로 미묘한 의미 차이(예: "almost" vs. "nearly")를 보수적으로 필터링.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: **리스크: 의미론적 동등성 가정의 한계**
FOL 변환 + 모델 체킹만으로는 **비교사전(synset)이나 PropBank의 범위 밖 맥락(예: 은유, 문화적 함의)**을 놓치며, 특히 **발화 목적·화용론적 뉘앙스(예: "sprint"가 '과시'로 쓰이는 경우)**는 NLI 모델로도 완벽히 포착되지 않는다. **의미 보존이 보장된 것처럼 자동화하면, 출제 원칙상 엄격한 ‘의미 변별성’ 요구를 어길 위험**이 있다.
- **교사#40530 (듣기·구어체·실용·상황형)**: **의사결정 트리 기반 다층 검증**을 제안한다.
**STEP 1**에서 **의미역(θ-roles) + 구문구조(PS-트리) 보존**을 **의미역 범위(θ-grid) 확장으로 보완**해 PropBank의 범주형 오류(예: '과시' 뉘앙스)를 **논리적 계층(θ-subtype)으로 필터링**하고,
**STEP 3**에서 **NLI 모델(예: RoBERTa-NLI) + 감정·화용 임베딩(예: VADER, Polarity Score)**을 결합해 **화용론적 위반(예: 'sprint'의 과시 효과)**을 **다중 레이블 분류**로 검증한다.
**최종 통과 조건**: **FOL 모델 체킹(논리적 동등성) + NLI + 화용 임베딩**의 **AND 조건**으로 의미 보존을 보수적으로 검증한다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: **새로운 관점: ‘의미 보존 다면성 등급제(MPG: Multi-faceted Preservation Grading) 도입’**

의미 보존을 **논리적 동등성(Level 1) + 맥락 등가성(Level 2) + 화용·담화 일관성(Level 3)**로 3단계 등급화하고, **각 단계 통과 시 자동으로 ‘출제 가능성 점수(MPS)’를 부여**하여 **출제 원칙(의미 변별성·맥락 일관성)과 기계 검증의 괴리**를 좁힌다. **Level 2는 EBS·수능 ‘맥락별 어휘 선호도 DB’(예: ‘sprint’는 ‘운동’ 맥락에서만 허용)를 기반으로 한 **‘맥락 임베딩 정렬(CEA: Contextual Embedding Alignment)’**로, **Level 3은 ‘화용 패턴 지식 그래프(PPKG)’**를 통해 **‘과시’·‘비꼼’ 등 문화적 함의를 **의도적 선택지로 필터링**한다. **이 등급제가 ‘의미 변별성’과 ‘맥락 일관성’을 기계적으로 검증할 수 있는 구조**를 제공하며, **출제자의 인지적 부담을 줄이는 동시에 검증의 투명성·재현성을 높인다.**
