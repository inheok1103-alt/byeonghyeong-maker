## 대화문
- **교사#54504 (담화·응집성·최상위 내신형)**: **찬성.**

**근거:**
1) 문항 간 '근거 중복'은 수능·내신의 '문항 간 독립성 원칙'에 위배된다(예: 2022 수능 가형 29번(문법)과 30번(어휘)이 동일한 구절을 근거로 사용).
2) 중복 근거는 '문제 난이도 조절'을 왜곡하며, '측정 타당성'을 저해한다(예: 내신 모의고사에서 한 단락이 두 문항의 근거로 반복 사용된 사례).

**구체적 구현 방법:**
1) **문항 제작 시** '근거 출처(본문/지문/단락)'를 고유 ID로 표기하고, 중복 ID 사용 시 시스템에서 자동 차단.
2) **검증 단계**에서 '문항-근거 매트릭스'를 출력해 사람이 직접 중복 여부 재확인(한국교육과정평가원 방식).
- **교사#95740 (화용·함의·패러프레이즈 정교형)**: **우려: '고유 ID 시스템'의 현실성 문제**

고유 ID 표기만으로는 문항 제작자의 '의도적 재배치'나 '변형된 인용'을 완벽히 차단하지 못한다. 예컨대, 동일 구절을 '재구성'해 표면적으로는 달라 보이지만 실질적으로는 동일한 근거를 사용하는 경우(패러프레이즈 중복)가 발생할 수 있으며, 이 경우 시스템은 이를 자동 감지하지 못할 가능성이 높다. 결국, 사람이 직접 검증하는 단계가 필수적이지만, 이 또한 '주관적 해석'에 따른 오류 가능성을 내포한다.
- **교사#42442 (교육과정·성취기준·함정 설계형)**: 고유 ID 시스템에 **의도적 변형 감지 알고리즘(예: 구문 구조 해싱 + 의미론적 유사도 점검)**을 결합해 패러프레이즈 중복을 자동 탐지하고, 검증 단계에서는 **다중 검토자(2인 이상)의 이중 블라인드 재검**을 도입해 주관적 오류를 최소화한다. 또한, '근거 범위'를 문항 유형(예: 화용 vs. 어휘)별로 분리해 중복 발생 가능성을 사전에 차단하는 카테고리 분류 체계를 도입한다.
- **교사#86610 (듣기·구어체·실용·상황형)**: **보완 제안:**
1) **‘의도적 변형 감지’ 최소 단위를 ‘의미 블록’(meaning block)으로 설정**해, 핵심 어휘/구문/문맥적 함의가 동일할 경우 자동 차단(예: *"He ran away"* vs. *"He fled"* → 동일한 근거로 간주).
2) **‘문항-근거 관계도’를 시각화하는 대시보드**를 도입해, 제작자·검증자·시스템이 실시간으로 중복 패턴을 탐지하고 즉각 피드백하도록 설계.
3) **‘과도한 재사용 패널티’ 시스템**을 적용해, 특정 지문이 너무 많은 문항의 근거로 쓰일 경우(예: 3회 초과) 자동 경고와 대체 지문 요청을 강제.
