# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-15T17:42:40.585Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 의미 보존 자동 검증 절차는 내신/수능 출제 원칙의 '의미 일관성'과 '맥락 정합성'을 충족하기 위해 필요하다는 점은 공감되나, 화용론적 뉘앙스(idiom, register, politeness) 손실을 사전에 차단하는 구체적 필터링 체계가 미비하다는 지적에 따라 보완이 필요함.
- 반영 방법: 1) BERT/RoBERTa 임베딩(0.85 Threshold) + WordNet Sense + FrameNet 맥락 분석을 기본 틀로 채택하되, 2) idiom/slang/eregister mismatch는 Frame Alignment Score(<0.3)로 자동 차단하고, 3) 다의어는 Dependency Parsing + SRL(Semantic Role Labeling)로 sense disambiguation 강화. 4) 화용론적 계층(Politeness/Register/Idiom Integrity)을 3단계 필터링(Pre-filtering→Contextual→Register Check)으로 구조화하여 내신/수능 ‘맥락 오용’ 채점 위험 최소화.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학(transformation-based engineering)의 L1 어휘 치환 시 **의미 보존 자동 검증 절차는 찬성**한다. 이유는:
1) **내신/수능 출제 원칙**상, 변형은 *의미 일관성*이 핵심인데, 자동 검증으로 변형 오류(예: 동의어 오용, 다의어 혼동)를 사전에 차단할 수 있기 때문.
2) **구체적 구현**은 **BERT/RoBERTa 기반 의미 임베딩 + 어휘 유사도 점수(WordNet/ConceptNet)** 결합: 치환 전후 문장의 임베딩 유사도를 0.85 이상으로 설정하고, 다의어/동음이의어는 *의존 문맥* 분석(예: "bank" → "river bank" vs. "savings bank")으로 필터링.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: 변형공학의 자동 검증이 *의미 보존*을 보장할 수 있다고는 해도, **문맥·화용론적 뉘앙스 손실**을 overlooked할 위험이 있다. 예를 들어, "He kicked the bucket"의 비유적 의미를 "그는 통을 걷어찼다"로 치환했을 때, BERT 임베딩은 유사도를 높게 산출하겠지만, *idiom* 파괴로 인해 **문맥 오류(meaning shift)**가 발생할 수 있다. 이는 내신/수능에서 **문법 오류(문맥 오용)**로 채점되어 점수 하락을 초래할 수도 있다.
- **교사#40530 (듣기·구어체·실용·상황형)**: **교사#28147 (실용·상황형 전문형, 12년차):**
의미 보존 검증은 **BERT 임베딩(0.85 상한) + 다의어/관용구 필터링(WordNet sense + 프레임 기반 맥락 분석)**에 *화용론적 등급(Politeness/Register)*까지 결합해야 한다. 예를 들어 "kicked the bucket"은 **idiom-sense mismatch**로 자동 차단하고, "He passed away"로만 치환 허용. 이렇게 하면 **문맥·화용 오류**를 사전에 제거하며, **내신/수능 출제 원칙**의 '의미 일관성'과 '맥락 정합성'을 동시에 충족한다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: 변형공학의 의미 보존 자동 검증은 **BERT/RoBERTa 임베딩(0.85Threshold) + 다의어/관용구 필터링(WordNet Sense + FrameNet 맥락 분석)**에 **화용론적 계층(Politeness/Register/Idiom Integrity)**을 **3단계 필터링(Pre-filtering→Contextual→Register Check)**으로 구조화해야 한다. 특히 *idiom/slang/eregister mismatch*는 **프레임 기반 맥락 일치성(FRAME ALIGNMENT SCORE <0.3)**으로 자동 차단하고, **다의어는Dependency Parsing + SRL(Semantic Role Labeling)**로 sense disambiguation을 강화해 내신/수능 ‘맥락 오용’ 채점 위험을 최소화한다.
