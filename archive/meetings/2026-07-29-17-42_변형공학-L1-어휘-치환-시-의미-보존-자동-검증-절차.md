# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-07-29T17:42:02.653Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: Siamese Network 기반 임베딩 거리의 한계를 보완하기 위해 의미역 레이블(PropBank ARG-Labels)과 의미역 일치율(ARI)을 추가 측정하는 안(교사#40530)과, 의도-행위 일관성 점수(IACS)를 도입하는 안(교사#84698)이 유의미한 보완점으로 인정됨. 그러나 화자 의도(예: 뉘앙스)까지 포괄하는 완전 자동화는 현실적으로 어려워 고도화 단계로 분류됨.
- 반영 방법: 1) Step2에 **의미역 일치율(ARI)**를 40% 가중치로 추가하여 임베딩 거리(60%)와 결합. 2) Step4로 **의도-행위 일관성 점수(IACS)**를 도입하여 *sipped→drank*와 같은 뉘앙스 차이를 규칙-데이터 하이브리드로 보완. 3) 최종 점수는 **의미 보존성 = (임베딩 거리×0.6) + (ARI×0.4) + (IACS×0.2)**로 산출.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학, 특히 **L1 어휘 치환 시 의미 보존 자동 검증**은 **구현 가능성(Yes)**이 있지만, **한계Point**를 반드시 고려해야 한다.

**근거**:
1. **의미보존성**은 문맥·의존관계·의미역 등 **다층적 분석**이 필수인데, 이는 **통계적/규칙 기반 모델(예: BERT + 의미역 태거)**로 어느 정도 검증 가능.
2. **한계Point**: **은유·암시·문화적 함축**은 기계가 온전히 포착하기 어려우며, **정확도 80% 내외**에서 정체.

**구체적 구현**:
- **Step1**: 어휘 치환 전후 문장에 대해 **의미역 레이블링(PropBank 등)** + **의미적 유사도 점수(WordNet/ConceptNet 기반)** 계산.
- **Step2**: **BERT/RoBERTa fine-tuning**으로 치환 전후 문장의 **문맥 임베딩 거리(Siamese Network)**를 측정.
- **Step3**: **규칙 기반 필터**로 **의존관계 파괴/문법 오류** 감지(Stanford Parser/UDpipe 활용).

**결론**: **기본 틀(70~80% 정확도)**은 가능하지만, **고도화(90%+)는 인공지능+인간 협업**이 필요.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: **우려Point**:
Step2의 **문맥 임베딩 거리(Siamese Network)**가 **의미 보존성**을 truly measure하는가? *Distributional Hypothesis*에 기반한 임베딩은 **의미 유사도**는 잡아내지만, **논리적/의미역적 일관성**은 놓칠 수 있어. 예: "He *sipped* the tea" → "He *drank* the tea"는 유사도가 높지만, *sipped*의 '조금씩 마시는 동작'은 *drank*로 대체 시 의미역 파괴가 발생할 수 있음. **임베딩 거리만으로는 이 미묘한 차이를 구분할 수 있을까?**
- **교사#40530 (듣기·구어체·실용·상황형)**: **보완 Point**:
Step2의 **Siamese Network 기반 임베딩 거리**는 **의미역적 일관성**을 직접 검증하지 못하므로, **의미역 레이블(PropBank ARG-Labels)**과 **의미역 일치율(ARI: Argument Role Identity)**을 추가 측정해야 한다. 이 둘을 **임베딩 거리 + 의미역 일치율**로 가중치 조합(예: 6:4)하여 최종 점수를 산출하면, *sipped → drank*와 같은 **동작 세부성 차이**를 포착할 수 있다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: **교사#11024 (패러프레이즈·레토릭·시스템 설계 전문)**:
Siamese Network가 *distributional*한 의미 유사도는 측정하지만 **ARG-Labels/ARI와 결합**하더라도 **화자 의도(예: '조금씩'이라는 뉘앙스)**는 여전히 미시적 맥락 분석(예: *duration/degree modifiers*)이 필요합니다. **Step4로 '의도-행위 일관성 점수(Intention-Action Consistency Score)'를 도입**하여, *sipped* → *drank* 대체 시 발생하는 **행위 목적(possession/ingestion)** 및 **양적/질적 변화(quantitative shift)**를 **규칙-데이터 하이브리드(규칙: 'sip' → 'ARG1의 양 감소'; 데이터: BERT fine-tuning with modal auxiliaries like 'just'/'slowly')**로 보완해야 합니다.
