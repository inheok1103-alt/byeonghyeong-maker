# 교사 회의록 — 변형공학: L1 어휘 치환 시 의미 보존 자동 검증 절차

- 일시: 2026-08-13T17:23:29.048Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 중)
- 사유: WordNet Sense Gloss의 한계를 프레임 시멘틱스가 보완하는 접근은 의미 보존 검증의 정교성을 높이나, 구현 복잡도와 계산 비용이 높아 실용성에서 한계가 있다. 또한, 상황 맥락의 BERT-style embedding 적용은 고수준의 기술력이 요구되어 수능·내신 출제 현장 적용에 제약이 따른다.
- 반영 방법: 1) **의존구문 트리 매칭(Dependency Tree Matching)**과 **의미역(θ-roles) 일치성 검증**을 1차 필터로 유지. 2) **프레임 시멘틱스 기반 검증**을 보조로 도입하여 *polysemy*와 *metaphor* 오류를 탐지. 3) WordNet Sense Gloss는 *hypernym/hyponym* 계층 분석으로 보완하여 과도한 계산 비용을 회피. 4) **상황 맥락 임베딩**은 선택적(optional)으로 적용 가능하도록 단계적 구현을 제안.

## 대화문
- **교사#52592 (언어학 이론·EBS 연계형)**: 변형공학의 의미 보존 자동 검증은 **찬성**한다.

**근거:**
1) L1→L2 어휘 치환 시 문법/의미 손상(예: *He kicked the bucket* → '버킷을 찬'은 치명적 오류)을 자동 탐지할 수 있어 수능 내신 출제 신뢰성을 높인다.
2) 통계적/규칙 기반 모델(예: WordNet + 어휘 의미역 레이블링)으로 '의미망'을 유지한 변환을 필터링할 수 있다.

**구체적 구현:**
- **단계 1:** 어휘 치환 전후의 [의미역(θ-roles)]과 [구문 역할]을 일치시키는 *Dependency Tree Matching* 실시.
- **단계 2:** 치환된 어휘가 속한 *Semantic Field*(예: *kick* → '죽음' 관련 동의어 *pass away*)와 호환되는지 *WordNet Sense Gloss*로 검증.
- **결과:** 불일치 시 경고(예: "Chicken의 '닭'→'용기'는 의미변질 위험")를 출력.
- **교사#93828 (담화·응집성·패러프레이즈 정교형)**: **리스크 지적:**
WordNet Sense Gloss 기반 검증은 *polysemy*와 *metaphor*를 충분히 포착하지 못한다. 예를 들어 *kick the habit*("습관을 버리다")에서 *kick*을 '죽음' 관련 동의어로 치환하면 *Semantic Field*는 유지되지만(둘 다 '제거'라는 상위 범주), 실제 의미는 완전히 달라진다. 이는 **의미 변질의 '미묘한 오류'**로, 수능 내신 출제 시 오답 선지 오염(예: *pass away the habit* 오답 선택지 유도)으로 이어질 위험이 크다.
- **교사#40530 (듣기·구어체·실용·상황형)**: **새로운 접근:**
의미 변질의 '미묘한 오류'를 잡기 위해 **프레임 시멘틱스(Frame Semantics)** 기반 검증 절차를 추가한다. 예를 들어 *kick the habit*의 경우, '습관 제거'라는 프레임 구조가 *pass away*로 치환될 때 '죽음' 프레임이 중첩되어 **의미역 불일치**가 발생함을 자동 탐지(예: *Agent*가 '습관'에서 '인간'으로 왜곡됨). 이는 WordNet Sense Gloss의 한계를 보완하며, **담화 수준의 응집성**까지 검증 가능하다.
- **교사#84698 (어휘·연어·패러프레이즈 정교형)**: **프레임 시멘틱스 + 어휘 네트워크 하이브리드 검증 시스템**을 제안한다.
프레임 구조(예: *habit removal frame*)와 *WordNet* Sense Gloss의 *hypernym/hyponym* 계층을 동시에 분석하여 *polysemy*와 *metaphor*의 미묘한 오류를 **프레임 일관성 점검**으로 보완한다.
또한, **상황 맥락( situational context )**을 *BERT-style contextual embedding*으로 보강하여 *kick the habit* vs. *pass away the habit*의 프레임 충돌을 정량적으로 탐지(예: *Agent* 역할의 *embedding distance* 임계치 초과 시 경고).
