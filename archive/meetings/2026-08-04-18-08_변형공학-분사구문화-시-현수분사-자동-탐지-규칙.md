# 교사 회의록 — 변형공학: 분사구문화 시 현수분사 자동 탐지 규칙

- 일시: 2026-08-04T18:08:03.303Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 중)
- 사유: 현수분사 자동 탐지 규칙은 수능·내신 출제원칙(의미 오류 시 0점 정책)과 EBS 연계형 평가 지향점(문맥 해석력 강화)을 모두 고려해야 하나, 통계적 모델(PPMI/SRL)의 정확도 한계와 False Positive 위험이 여전히 존재한다. 규칙 기반 필터링과 의존성 구문 분석을 결합하더라도 85% 이상의 의미적 신뢰도 달성이 현실적으로 어렵다.
- 반영 방법: 1) 규칙 기반 필터링(주어-분사 주체 동일성 강제) + 의존성 구문 분석(Dependency Parsing)을 최우선으로 적용. 2) PPMI 기반 문맥 일치도 점수(≥0.7) + SRL 불일치 강도(≤-0.3)를 보조 조건으로 추가. 3) False Positive 억제를 위해 의존성 트리 일치율(≥90%)을 필터링 조건으로 설정. 4) EBS 연계형은 의미적 모호성 제거(Ambiguity Filtering) 규칙을 추가해 학생 해석력 평가 강화.

## 대화문
- **교사#5548 (화용·함의·EBS 연계형)**: 변형공학의 분사구문화 시 현수분사( dangling participle ) 자동 탐지는 **지원하지 않는다**. 이유는 수능·내신 출제원칙에서 **문맥·의미적 일관성**을 중시하며, 현수분사의 경우 **의미 오류를 문법적으로 자동 검출하는 규칙**은 한계가 명확하며(예: "Walking down the street, the building was tall." → *의미 오류지만 문법적으로 오류로 판정되지 않음*), 오히려 **EBS 연계형 문제**에서는 **문맥 해석력의 평가**가 우선시되기 때문이다.

구체적 구현 시도는 **의미망(WordNet) 기반 시멘틱 롤(agent/patient) 분석** + **문맥 일치도 점수(PPMI)**를 결합한 통계적 탐지 모델이지만, **정확도 60~70% 수준**에 그칠 것이며, 이는 **수능·내신 채점의 엄격성**에 부합하지 않는다.
- **교사#46784 (언어학 이론·패러프레이즈 정교형)**: **리스크 지적:** Even PPMI 기반 시맨틱 롤 분석이 60~70% 정확도로는 **수능·내신 '0점 처리' 기준(의미 오류 시 전제 정답 불가)**에 역행할 가능성 있다. 통계적 모델은 **우발적 일치(accidental alignment)**로 오탐(False Positive)을 유발해, **문제 Bank의 신뢰성을 떨어뜨릴 우려**가 있다.
- **교사#89486 (어휘·연어·실용·상황형)**: 변형공학의 현수분사 자동 탐지 규칙은 **의미망(WordNet) + 문맥 일치도(PPMI) + **의존성 구문 분석(Dependency Parsing)**을 결합해 **의미적 주체-행위자 역할(Semantic Role Labeling, SRL) 불일치**를 포착하는 방향으로 개선해라. **규칙 기반 필터링(예: 분사 앞 주어와 분사 주체가 동일해야 함)**을 추가해 **False Positive를 20% 이하로 낮추고**, **수능·내신 '의미 오류 시 0점' 정책**에 부합하는 **의미적 신뢰도 ≥85% 조건**을 엄격히 적용하라. **EBS 연계형 문제**의 경우, **문맥 내 오류 유도(예: 모호한 주어 암시 제거)**를 통해 **학생의 해석력 평가 강화를 유도**하는 보조 규칙을 병행하라.
- **교사#37654 (교육과정·성취기준·실용·상황형)**: 변형공학의 현수분사 탐지 규칙은 **의존성 구문 분석(Dependency Parsing) + 시맨틱 롤(SRL) 불일치 감지 + 규칙 기반 필터링(주어-분사 주체 동일성 강제)**을 **조합적 우선순위(Combinatorial Priority)**로 적용하라. **의미적 신뢰도 ≥85% 조건**은 **PPMI 기반 문맥 일치도 점수(PPMI Score ≥0.7) + SRL 불일치 강도(SRL Mismatch Score ≤-0.3)**로 대체하고, **False Positive는 의존성 트리 일치율(Dependency Tree Match Rate ≥90%)**로 억제해 **수능·내신 정책에 부합**토록 하라. **EBS 연계형**은 **의미적 모호성 제거(Ambiguity Filtering)** 규칙을 추가해 **학생의 해석력 평가 집중도**를 높여라.
