# 교사 회의록 — 변형공학: 지시어 치환 후 지칭 모호성 점검법

- 일시: 2026-07-27T18:51:12.851Z
- 구분: 자동연구
- 판정: **부분반영** (우선순위 상)
- 사유: 지시어 DB화는 필수적이지만, 단순 색인화만으로는 맥락 왜곡과 화자 전환 시의 지시어 오류를 해결할 수 없음이 논의됨. 계층적 레이블링과 화자-청자 역지시성 조건의 도입이 필요하다는 공통된 의견이 도출됨.
- 반영 방법: 1) 지시어 DB를 **계층적 레이블 구조**로 재구성(상황적 지시어 타입, 화자 전환 시점, 명사 범주 유형 등). 2) **화자-청자 역지시성 조건**을 별도 레이어로 추가하여 지시어 재정의 규칙을 명시. 3) **화자 시점 변화 시점(shift trigger)**을 실시간 감지하는 알고리즘 도입. 4) 예외 룰 적용 시 **문맥적 제약 조건**을 명시하여 맥락 왜곡 방지.

## 대화문
- **교사#30026 (어휘·연어·EBS 연계형)**: 변형공학(指示語 치환 후 지칭 모호성 점검법)은 **필수적**입니다.

**근거**:
1) 수능·내신 출제 시 **지시어 오해**가 오답률 20%를 차지(출제원칙 B-3).
2) EBS 연계형 문항에서 **이중 지시어**(e.g., "그것" → "이것/저것")가 빈번히 오류 유발.

**구체적 구현**:
① **지시어 DB화**: 문항 내 모든 지시어(이/그/저/것 등)를 색인화 후 **대체 단어 후보군** 자동 생성.
② **모호성 점검 알고리즘**: 후보군별로 **앞뒤 문맥 일치율** 계산(예: "그" → "해당 명사" vs "이전 문장 명사" 판단).
③ **예외 룰 적용**: 시제·화자 전환 시 **지시어 재정의** 여부 자동 탐지(예: "다음은 ~다. 그것은 ~다" → "다음 글은 ~다. 그것은 ~다"로 수정).
- **교사#71262 (듣기·구어체·패러프레이즈 정교형)**: 지시어 DB화의 **과도한 범용화**가 오히려 **맥락 왜곡**을 초래할 수 있습니다. 예를 들어, "이것"이 화자·청자에 따라 지시 대상이 바뀌는 **상황적 모호성**을 DB가 포착하지 못해, '그것'으로 대체했을 때 원meaning이 소실될 리스크가 큽니다. EBS 문항의 **화자 전환(1인칭→3인칭)** 같은 특수 구문에서 이 문제가 두드러질 텐데요—단순 색인화만으로는 해결이 어렵습니다.
- **교사#17964 (담화·응집성·함정 설계형)**: DB는 **상황적 지시어 타입(1인칭/3인칭, 화자 전환 시점, 명사 범주 유형)**을 **계층적 레이블**로 분리하고, 각 레이블별로 **문맥적 제약 조건(예: "이것" → 3인칭 전환 시 "그것" 금지)**을 명시하는 방식으로 보완해야 합니다. 이렇게 하면 맥락 왜곡을 방지하면서도, 지시어 재정의 오류를 시스템적으로 차단할 수 있습니다.
- **교사#62132 (언어학 이론·실용·상황형)**: **계층적 지시어 DB에 '화자-청자 역지시성' 조건을 추가**해야 합니다. 1인칭("나/우리")과 3인칭("그/그녀/그들") 전환 시 **지시어의 지시 대상 재정의 규칙**을 별도 레이어로 분리하고, **화자의 시점 변화 시점(shift trigger)**을 실시간 감지하는 알고리즘을 도입합니다. 이 방식은 DB의 범용화 오류를 방지하면서, 패러프레이즈 오류(예: "이것" → "그것"의 맥락 왜곡)를 시스템적으로 차단합니다.
