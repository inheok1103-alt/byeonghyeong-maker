# 분석지 생성 로직 (sheet.html 파이프라인)

원천: `Downloads\분석지 제작` 생산 OS — 2026-06-22 확정 "이상적 분석지" 정본(outputs/_design_sample_ideal) + RAY_UNIVERSAL_COLOR_SYSTEM + 1-3-5 인지부하 규격(_공통템플릿/109). 이를 웹(sheet.html)으로 이식해 누구나 지문만 붙여넣으면 정본 디자인 분석지를 생성.

## 디자인 불변 규칙 (정본)
- 판형: **A4 가로(297×210mm) 2쪽** — 1쪽=본문 분석, 2쪽=시험 정리. 1페이지 1목적.
- 색 = **독해 기능**(주제 아님) 6색: 핵심개념 Blue #2563EB / 조건·근거 Green #16845B / 논리·전환 Amber #B45309 / 문법·구문 Rose #C0265A / 주장·출제핵심 Purple #6D45B8 / 보조 Gray #59616E.
- 인지부하 1-3-5: 한 화면 핵심 블록 ≤3, 암기 항목 ≤5.

## 페이지 구성 스키마
**P1 본문 분석**: 헤더(메타·제목) → 핵심 쟁점(thesis) → 색 범례 → 문장별 행(번호·영문(기능색 하이라이트)·해석·담화역할 칩·출제 포인트) → 하단(본문 전개 flow 3~4단계 + 출제 핵심 4셀: 주제·제목/빈칸/순서·삽입/어법 — 근거 문장번호와 함정 명시).
**P2 시험 정리**: 한눈 요약(주제·목적·요지·주장) + 제목 후보 → MCQ→서술형 전환 루프 3개(과제+채점기준) → 복습 카드 3장(암기 문장/핵심어/함정) | 패러프레이즈 표 6~7행(원문 표현→시험 치환형→출제 태그) → trap words 3~4행 → 정답 근거 한 줄(anchor: 어느 문장으로 수렴하는지).

## 생성 파이프라인 (2엔진 병렬)
1. **엔진A(문장별)**: title·issue·genre·diff + sents[](en/ko/role/pt/hl[]) + flow[] + exam4[]. hl.t는 **그 문장에 실존하는 원문 구절 그대로**여야 하며 코드가 indexOf로 검증 — 없는 구절은 무시(환각 게이트).
2. **엔진B(시험정리)**: summary·titles·loop(루브릭 포함)·review·para·trapwords·anchor.
3. 렌더러: LLM 출력의 HTML은 전부 escape 후 코드가 태그 생성(태그 주입 차단). **굵힘은 \*\*마크\*\*만 허용.**

## 품질 게이트
- 문장 수 = 지문 문장 수(엔진A schema 강제) / hl 실존 검증 / 30단어 미만 지문 거부.
- 색 오용 금지: hl.c는 5색 enum 외 무시.
- 인쇄: @page A4 landscape, 배경 그래픽 켜기 안내. 브라우저 인쇄→PDF가 배포 경로.
