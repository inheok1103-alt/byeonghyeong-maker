# 경찰대·사관학교·고등내신 종단분석 → 출제 로직/파이프라인/하네스

생성 2026-07-09 · 근거: 경찰대 2014–2020(로컬 flow.txt) + 사관학교 2022–2026(로컬 txt) + 고등내신(인터넷 종단조사). 목적: 수능 위·아래 난도 대역을 실측해 엔진 난이도·유형·서술형 로직을 확장. 원칙(Ray): 많이 만들되 최종은 신뢰도·타당도·변별도로 자른다.

## 0. 한 줄 결론 3개
1. **난도 대역이 한 칸 더 있다.** 내신기본 ≤ 하 < 수능표준 = 중 < 수능킬러 = 상 < **경찰/사관 킬러 = 초킬러(신설)**. '상=킬러'로 닫아둔 현 3단을 4단으로 뚫고, 초킬러는 원전급 렉사일·파싱부하를 **제4 변별축**으로 얹는다.
2. **언어형식을 이중 검증한다.** 사관·경찰은 어법2+어휘2를 앞머리에 붙박이(밑줄형+네모형 병행). 단일 grammar/vocab 빌더로는 못 담는다 → 어법-밑줄/어법-네모, 어휘-밑줄/어휘-네모로 분리.
3. **내신은 고르기가 아니라 쓰기·검수 게임이다.** 서술형 30~50%, 조건 누락·철자·어형 하나로 등급이 갈린다 → 조건을 산문 guide에서 **독립 슬롯**으로 구조화 + '허용답안집합·금지표현집합·0점트리거' 루브릭을 코드로 산출·검증.

## 1. 시험 프로필(성격·수능과의 차이·난도 위치)
### 사관학교 1차 영어 — 순수 독해형
- 30문항(3점20+4점10=100), **듣기 전면 부재** → 전 문항 어법·어휘·독해. 수능(듣기17+독해28, 어법1·어휘1) 대비 **언어형식 2배 검증**(어법2+어휘2 앞머리 고정, 밑줄+네모 병행).
- 소스의 **사료화**: 철학원전(도덕상대주의·서얼 중국어방)·진화생물학·과학사(허블 구면수차)·고전서사(칸나이 전투)에 각주 3~4개. 난도 = 수능 최고난도 이상.
- 4점 킬러 10문항 = 빈칸(15–19,26)·순서21·삽입23·요약24 집중.
- **종단 2022→2026**: 수능 코어로 수렴(함의↓, 빈칸4→5·요지1→2·제목2→3↑), 배점 전면공개, **어법 탈네모**(2026 밑줄2). 변별 = 표면 어휘일치가 아닌 '전체 명제의 추상적 재진술', 오답 = 지문어 재활용 **어휘루어(lexical lure)**.

### 경찰대 1차 영어 — 어휘·어법 프론트로딩
- 45문항(2점35+3점10=100), 7개년 문항수·배점 불변. **1~13번(약 27~29%)을 동의어·어법오류·낱말부적절·A/B/C 네모어휘로 붙박이**(수능은 어법+어휘 합 약5%).
- 어휘 **CEFR C1+ 성인 학술어**(sockdolager·charlatan·abjure), 지문 = 성인 논픽션 원전(Adam Smith·Hobbes·dark matter·블록체인). 난도 = 수능보다 통사밀도·추상도·배경지식 한 단계 위.
- 3점 10문항(추상빈칸·철학지문·5지 지칭·43–45 장문세트)이 상위권 변별.
- **종단**: 시사·과학 논증 강화, 심경 단일→심경변화(A→B) 이원화, 지칭+어휘쓰임 결합으로 문항밀도↑.

### 고등내신 — 별종 시험(인터넷 종단조사)
- 출제=학교 교사, 지필 30~50%가 서술형·논술형(조건영작·오류수정·요약), **외부지문**(수능·모평·CNN) 대량, 채점=감점·조건폐쇄식 수기(부분점수 인색).
- 결정적 차이 = 평가 축: 수능 100% 폐쇄형 '고르기', 내신은 학생이 답안을 **생성하는 '쓰기·검수'** → 조건 누락·철자·어형 하나로 등급이 갈림.
- 난도 위치: 대치/강남권 킬러는 교과서 대비 약 **4개 학년 위**(고1 시험에 고3 수능지문).
- **종단(국가 로드맵)**: 서·논술 비중 **2027 30% → 2028 40% → 2029 50% → 2030+ 50%↑** 구조적 우상향. 객관식 변별 축소·채점기준표 표준화·AI 보조채점 수요 동반.

## 2. 난이도 대역 4단 재정의(difficulty calibration)
```
[내신기본 ≤ 하] < [수능표준 = 중] < [수능킬러 = 상] < [경찰/사관 킬러 = 초킬러(신설)]
```
- **상**은 '수능 최고난도'로 유지, **초킬러**는 원전급 렉사일·파싱부하를 별도 변별축으로 얹는다.
- master 3축(추론단계 × 패러프레이즈거리 × 오답매력도)에 **제4축 '통사밀도/파싱부하'**(문장길이30어+·내포절 중첩·삽입절로 진주어/목적어관계 추적) 추가 — 초킬러 전용. 사관2026 허블·어법이 '문법지식'이 아닌 '긴 문장 파싱'으로 변별점을 옮긴 사실 반영.
- 공정성 가드: 초킬러에도 '정답은 본문 단서로 유일 도출·배경지식 비의존' 유지.

### 유형별 난도 로직(초킬러 확장)
- **빈칸**: 정답 = 지문 표면어와 편집거리 큰 패러프레이즈(요약문/논리피벗/예시일치/단서구 4폐쇄 중 1택), 오답5 중 ≥2는 지문 실제어휘 재조합(어휘루어). 난도 = 추상격차 × 루어개수. 초킬러 = lure≥3 + 장문빈칸.
- **어법**: 단일 명백오류 + 4개 매력적 정문법 폐쇄. 난도↑ 시 함정을 '흔히 오해하는 정문법'(관계사·분사·강조 it-that·병렬·수동)으로. 하=인접단서 단일규칙, 중=수식어개입/병렬, 상=규칙충돌·구조복원, 초킬러=긴 학술문장 주술·목적어관계 추적(파싱 자체가 변별).
- **어휘**: '어려운 단어 뜻'이 아니라 '문맥 방향 반전'으로 난도. 방향성 토큰(증가/감소·인과·대조) 태깅 → 정답 오용어를 문맥방향 반의어로 치환(spike↔drop, amplify↔suppress). 상/초킬러=결론부(대개 ⑤) 역행어 + 문단대조 반전어.
- **함의**: 정답=논지 추상 재진술, 오답4 중 ≥2=메타포 구성어 문자직역 미끼. 사관 종단상 축소(4~5→1) → 초킬러 세트는 비중↓, 빈칸으로 이전.
- **순서·삽입**: 지시어(this/these/such/it)–선행사, 연결어(however/Rather)–논리 참조사슬 그래프로 유일해 폐쇄 검증. 난도=연결어 약화+지시어 다중중첩+서사 인과사슬. 오답배열엔 '그럴듯한 오참조' ≥1 심기.
- **무관·불일치·지칭**: 무관=주제어 공유(위장)+논리단절, 제거 시 전후 지시·연결 복원 검증. 불일치=타임라인 구조화 후 국적/수치/긍부정/예외절/장소 5축 중 '하나만' 반전. 지칭=2인+ 서사 대명사-선행사 4:1 분기.
- **서술형**: 조건 개수·오류수정 N을 난도 노브로. 하=3단어·N=1·단일조건, 중=5단어·N=2·2중조건, 상/내신킬러=복합 2~3중조건(패러프레이즈 강제+구조 강제)·N=3·축약영작. 국가 로드맵(30/40/50%)을 학년도 파라미터로 받아 세트 내 서술형 최소비중 게이트로 강제.

## 3. 엔진 반영안(파이프라인/하네스)
- **P0 난이도**: types_v2 ◆난이도에 '초킬러' 단(상 상속 + 통사밀도·어휘루어≥2~3·원전급 렉사일) 추가. 코드빌더/LLM빌더 프롬프트에 제4축 주입.
- **P0 이중검증 유형**: 어법→어법-밑줄/어법-네모, 어휘→어휘-밑줄/어휘-네모 분리. 학교/시험 프리셋(사관2026·경찰대상)으로 슬롯 자동편성. 각 유형에 lexical_tier(C1/C2)·source domain(경제/철학/과학/시사/전기/서사) 태그.
- **P0 서술형 슬롯화**: 조건을 WORDLIMIT/ALLWORDS/TRANSFORM/PARAPHRASE(금지·강제)/STRUCTURE(관계사·분사·가정법 강제) 독립 슬롯으로. 생성 직후 조건충돌 검증(단어수제한 < 필수단어수 등) + 예시답안·허용답안집합·금지표현집합·앵커답안(만점/부분/0점) 산출. 루브릭 내용40·형식35·어법철자25 + 조건별 0점트리거 분리 필드.
- **P1 오답생성 2모듈 명문화**: (A)어휘루어=정답 패러프레이즈와 편집거리 크게, 오답에 지문 실제어휘 재조합. (B)세부비틀기=사실슬롯(수치/국적/인물관계/긍부정/예외절) 정확히 1개 반전. 검증기에 유형별 폐쇄 불변식(어법=위반 1개, 개수형=카운트 일치, 어휘=정답 성립+오답4 불성립, 무관=제거 시 복원).
- **P2 세트 오케스트레이션**: 순서/삽입 그래프 유일해 폐쇄, 지칭 4:1 분기, STROKE 6축 커버리지 리포트로 편중 방지, '서술형 최소비중 게이트'(학년도 30/40/50%)로 로드맵 미달 세트 차단. 사관 2022→2026 유형가중치 선형보간 '종단 슬라이더'.

## 4. 신규 템플릿(new_templates)
- **장문 3문항 세트**(경찰대 43–45): 1지문에 순서+제목/주제+빈칸/어휘 3문항 묶어 지구력 변별. 논증-반박(Mozart effect) 구조 포함.
- **어법-네모(A/B/C 3쌍)**: 대립 문법쌍 3쌍 동시판단. 사관2026 프리셋은 비활성(탈네모), 내신 어법함정형은 활성 토글.
- **어휘-네모(반의쌍 3개)**: concealing/revealing·avoidable/inevitable식 반의쌍 + 결정근거 접속어를 문장에 함께 삽입, 담화논리로만 결정.
- **동의어-단문형**(경찰대 1~13 프론트로딩): 문장1개+밑줄 저빈도 학술어, 오답4=같은 의미장 근접어(문맥대체 불성립). 산출물을 학술어휘 카드로 재활용(워드리스트 채굴장).
- **서술형 조건-루브릭 통합(THE EYE 8종)**: 보기단어 모두사용/어형변형/영영풀이+첫글자/오류 N곳 수정/패러프레이즈 금지·강제/구조 강제/능수동 전환/주제문 축약영작. 각 코드에 3분할 루브릭+0점트리거+6칸 자가검수 체크박스.
- **논술형(단문 요약·의견쓰기)**: 로드맵 50% 대비. 예시답안+허용범위+금지표현으로 채점 폐쇄, 학년도 파라미터로 비중 스케일링.
- **전기 불일치**: 인물 타임라인을 경로/장소/연도/수용거부 슬롯으로 구조화 후 정확히 1슬롯만 반전(수능 26–28 상위호환).

## 5. 뇌+신경다발 연계(진화층 환류)
- 이 md를 연구층에 상시 편입 → server_brain이 매시간 참조, TYPERULE로 유형 프롬프트에 초킬러·이중검증·서술형슬롯 주입.
- 측정층(addon_psychometric): 초킬러 문항은 P̂ 대역을 낮춰(더 어렵게) 게이트, 어휘루어 오답의 distractorEff를 별도 확인. 실패 패턴은 logic_evolve로 로직층 환류.
