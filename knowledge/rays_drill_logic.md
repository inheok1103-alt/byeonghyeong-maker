# Ray's Drill 출제 로직 총정리

작성일: 2026-07-08  
대상: 고등학교 영어 내신 대비 문제은행, Ray's 동형모고, 실전 배부용 시험지  
용도: Codex/Claude 협업 출제 파이프라인의 기준 문서

---

## 0. 한 줄 정의

Ray's Drill 출제 로직은 **원문을 보존하되, 문제 유형에 맞게 지문 자체를 정직하게 조작하고, 기능적 오답과 현실적인 서술형 조건을 붙여, 실제 학교 시험지처럼 배부 가능한 문제은행을 만드는 방식**이다.

---

## 1. 최상위 원칙

### 1.1 많이 만들되, 최종본은 품질로 자른다

문제은행은 최대한 많이 만든다.  
다만 최종 학생 배부판에는 검수된 문항만 남긴다.

초안 단계:

- 지문별로 가능한 유형을 넓게 시도한다.
- 원문, 어휘 변형, 구문 변형, 전체 변형 버전을 만든다.
- 객관식과 서술형을 모두 생성한다.

최종 단계:

- 이상한 선지는 제거한다.
- 정답이 애매한 문항은 제거한다.
- 지문 조작이 안 된 문항은 제거한다.
- 해설이 빈약한 문항은 보강하거나 제외한다.

기본 판단:

```text
문항 수가 많은 허술한 판 < 문항 수가 줄어도 배부 가능한 판
```

### 1.2 실제 시험처럼 보여야 한다

문제가 좋더라도 시험지처럼 보이지 않으면 배부용 품질이 아니다.

필수 조건:

- DOCX 우선 제작
- 필요 시 PDF 변환
- 한 면 2단 구성
- 문항 간 여백 확보
- 지문과 선지의 시각적 구획 명확화
- 불필요한 글머리표 제거
- 글이 잘리지 않게 조판
- 서술형 답안란 중복 금지

### 1.3 학생이 실제로 풀 수 있어야 한다

난이도는 올릴 수 있다.  
하지만 불친절함으로 어렵게 만들면 안 된다.

좋은 난이도 상승:

- 오답 매력도 상승
- 논리 추론 단계 증가
- 지문 변형 강도 상승
- 근거 문장 간 거리 증가
- 내용 이해와 어법을 결합

나쁜 난이도 상승:

- 힌트 부족
- 단어 수 부정확
- 선지 모호화
- 정답 근거 불명확
- 지문 밖 배경지식 요구
- 고1 범위를 넘는 문법 함정

## 2. 자료 사용 로직

### 2.1 자료별 역할

| 자료 종류 | 역할 |
|---|---|
| 수특라이트 | 주요 문제은행 원천 지문 |
| 교과서 본문 | 내신형 내용 이해·어법·서술형 강화 |
| 교과서 대화문 | 대화 흐름, 상황 이해, 응답 완성 |
| 모의고사 지문 | 수능형 유형 확장 |
| 학교 기출 | 실제 내신 문항 구조, 선지 밀도, 서술형 조건 학습 |
| 프롬프트 TXT | 유형별 제작 방식 참고 |
| 단어장/숙어장 | 어휘 난이도 조절, 해설 어휘 보강 |
| 구문 자료 | 어법·서술형·구문 해설 보강 |
| 분석지 | 지문별 핵심 구조, 어휘, 구문, 출제 포인트 참고 |

### 2.2 참고와 베끼기의 구분

참고할 것:

- 유형 구성
- 발문 방식
- 선지 길이
- 오답 설계 방식
- 서술형 조건 제시 방식
- 해설 항목 구성
- 시험지 조판 느낌

베끼면 안 되는 것:

- 기출 문항 그대로
- 기존 선지 그대로
- 해설 문장 그대로
- 지문을 왜곡한 축약본

### 2.3 범위 처리

출제 전 반드시 범위를 확정한다.

확인 항목:

- 포함할 강/과/번호
- Gateway 제외 여부
- 대화문 포함 여부
- 추가 지문 제외 여부
- 본문 전체 사용 여부
- 특정 번호만 사용할지 여부

예시:

```text
수특라이트 04·05·07강: Gateway 제외
07강: 3, 4번 지문 출제
교과서 3과 본문: 대화문이어도 사용
추가 지문/대화문 제외 지시가 있으면 제외
```

## 3. 지문 처리 로직

### 3.1 절대 금지: 지문 축약

지문은 줄이면 안 된다.  
문제 유형상 필요한 조작은 가능하지만, 내용량을 줄이는 축약은 금지한다.

금지:

- 중략
- 생략
- 핵심 문장 삭제
- 긴 지문을 요약문으로 대체
- 문단 일부만 남기고 출제
- 정보량을 줄인 변형

허용:

- 어휘 변형
- 구문 변형
- 문장삽입용 문장 제거
- 빈칸 처리
- 어법 오류 삽입
- 어색한 문장 삽입
- 주제 동일 전체 변형

### 3.2 원문 보존과 문제 조작의 차이

원문 보존은 “지문의 정보량과 논리를 보존한다”는 뜻이다.  
문장삽입이나 빈칸 문제에서 아무 조작도 하지 말라는 뜻이 아니다.

예:

```text
문장삽입 문제:
원문 전체를 그대로 두면 안 됨.
삽입할 문장을 실제로 제거해야 함.
```

```text
빈칸 문제:
정답 표현을 지문 안에 그대로 남겨두면 안 됨.
정답 부분을 실제로 빈칸 처리해야 함.
```

### 3.3 변형 단계

Ray's Drill은 지문을 네 단계로 운용한다.

| 단계 | 이름 | 설명 | 목적 |
|---|---|---|---|
| T0 | 원문 그대로 | 원문을 거의 그대로 제시 | 기본 내용 이해 |
| T1 | 어휘 변형 | 핵심어·표현을 동의어/상위어로 전환 | 암기 방지 |
| T2 | 구문 변형 | 수동/능동, 관계사, 분사 등 구조 전환 | 구조 이해 |
| T3 | 전체 변형 | 주제와 논리는 유지하고 새 지문으로 재작성 | 고난도 응용 |

### 3.4 변형 시 보존해야 할 것

항상 보존:

- 주제
- 핵심 주장
- 필자의 태도
- 논리 흐름
- 인과관계
- 대조관계
- 예시의 기능
- 결론의 방향
- 정보량

바꾸어도 되는 것:

- 단어
- 문장 구조
- 예시의 표현 방식
- 담화 형식
- 지문 표면 배열
- 일부 표현의 추상도

## 4. 공통 지문 로직

### 4.1 문제용 지문 중복 금지

공통 지문을 주고, 다시 문제용 지문을 따로 주면 안 된다.

나쁜 구조:

```text
[공통 지문]
원문 전체

[문항]
다음 문장이 들어갈 위치는?
주어진 문장: 원문 속 문장
```

학생은 공통 지문에서 해당 문장을 찾아 답을 알 수 있다.

### 4.2 올바른 구조

문제 조작은 공통 지문 안에 반영한다.

| 유형 | 공통 지문 처리 |
|---|---|
| 빈칸 | 정답 표현을 실제 빈칸으로 바꿈 |
| 문장삽입 | 삽입 문장을 제거하고 위치 표시 |
| 글의 순서 | 블록을 분리해 재배열 |
| 어법 | 밑줄 또는 오류 지점 표시 |
| 어휘 | 문맥상 판단할 단어 표시 |
| 어색한 문장 | 어색한 문장을 실제 지문 안에 삽입 |
| 요약문 | 지문은 제시하고 요약문에서 핵심어 빈칸 |

### 4.3 한 지문당 문항 수

기본:

- 1문항
- 2문항
- 3문항

금지:

- 무조건 3문항
- 한 지문에 4문항 이상 과밀 배치
- 같은 지문에서 앞 문제 선지가 뒤 문제 힌트가 되는 구조
- 공통 지문에 여러 조작을 동시에 넣어 혼란스럽게 만드는 구조

### 4.4 문제은행에서 문항 수 늘리는 방법

한 지문에 문항을 몰아넣지 말고, 변형 버전을 나눈다.

예:

```text
SL04_EX01_T0: 내용일치 1문항
SL04_EX01_T1: 빈칸 1문항
SL04_EX01_T2: 어법 1문항
SL04_EX01_T3: 주제문 서술형 1문항
```

## 5. 유형 선택 로직

### 5.1 지문 성격별 추천 유형

| 지문 성격 | 적합 유형 |
|---|---|
| 핵심 주장 선명 | 주제, 요지, 제목, 주제문 서술형 |
| 논리 전개 뚜렷 | 빈칸, 문장삽입, 글의 순서, 연결어 |
| 세부 정보 풍부 | 일치/불일치, 내용 이해 |
| 대조·반전 구조 | 빈칸, 요지, 어색한 문장 |
| 예시와 일반화 구조 | 순서, 삽입, 요약문 |
| 구문 복잡 | 어법, 구문 포인트, 핵심문장 복원 |
| 대화문 | 상황 이해, 응답 완성, 인터뷰형, 의도 파악 |
| 설명문 | 주제, 요지, 빈칸, 어법, 요약 |
| 논쟁적 글 | 주장, 목적, 태도, 주제문 서술형 |

### 5.2 유형 배제 로직

억지로 유형을 끼워 맞추지 않는다.

배제 예:

- 주장성이 약한 설명문에 주장 유형 강제
- 세부정보가 거의 없는 지문에 일치/불일치 강제
- 연결 단서가 약한 지문에 문장삽입 강제
- 문법 포인트가 애매한 문장에 어법 강제
- 결론이 약한 지문에 주제문 서술형 강제

## 6. 객관식 유형별 출제 로직

### 6.1 주제

측정:

- 글 전체의 중심 생각
- 사례와 결론의 위계
- 반복되는 핵심 개념

정답:

- 글 전체를 포괄
- 사례가 아니라 일반화된 결론
- 너무 넓거나 좁지 않음

오답:

- 사례 하나를 주제로 일반화
- 핵심 원인과 결과 전도
- 주제 범위 과잉 확장
- 주변 소재로 초점 이동

검수:

- 정답만 지나치게 추상적인가
- 오답도 본문과 연결되는가
- 선지 길이가 비슷한가

### 6.2 요지

측정:

- 필자가 궁극적으로 말하려는 바
- 근거와 결론의 관계

정답:

- 결론 문장에 가까움
- 주제보다 주장성이 조금 더 강함

오답:

- 근거를 결론처럼 제시
- 세부 사례를 핵심으로 오해
- 필자의 태도를 약화하거나 과장

### 6.3 제목

측정:

- 핵심 내용을 압축하는 능력

정답:

- 소재와 논지 모두 반영
- 너무 길지 않음
- 과장된 표현 피함

오답:

- 소재만 맞고 논지 없음
- 논지는 있지만 소재가 어긋남
- 너무 세부적
- 너무 광범위

### 6.4 주장

측정:

- 필자의 권고, 판단, 당위

적합:

- 해결책 제시 글
- 설득형 글
- 가치 판단이 있는 글

부적합:

- 정보 설명문
- 객관적 소개문
- 단순 사례 나열

### 6.5 목적

측정:

- 글쓴이의 의도
- 요청, 안내, 설득, 경고, 홍보 등 기능

적합:

- 이메일
- 공지
- 안내문
- 연설문
- 편지
- 인터뷰형 자료

### 6.6 빈칸

측정:

- 앞뒤 문맥
- 논리 연결
- 핵심 개념 복원

좋은 빈칸:

- 결론 핵심어
- 대조 뒤 반전 표현
- 인과관계 결과
- 예시를 일반화하는 표현
- 글 전체를 압축하는 표현

나쁜 빈칸:

- 고유명사
- 수치
- 앞에 그대로 반복된 단어
- 문법만 맞추면 되는 자리

선지:

- 품사와 구조가 모두 들어맞아야 함
- 정답은 앞뒤 문맥 모두 만족
- 오답은 일부 문맥만 만족

### 6.7 문장삽입

절차:

1. 원문에서 응집성이 강한 문장 선택
2. 해당 문장을 제거
3. 남은 지문에 위치 표시
4. 제거 문장을 주어진 문장으로 제시
5. 정답 근거를 지시어·연결어·반복어·정보 순서로 설명

좋은 삽입 문장:

- this, these, such 등 지시어 포함
- however, therefore 등 연결어 포함
- 앞 문장을 받아 뒤 문장을 여는 기능
- 아무 곳에나 들어가지 않음

오답 위치:

- 앞뒤 한쪽만 그럴듯함
- 지시어 선행사가 없음
- 예시와 일반화 순서가 깨짐
- 대조 연결이 어색함

### 6.8 글의 순서

절차:

1. 지문을 기능 단위로 3블록 분리
2. 각 블록의 담화 기능 지정
3. 연결어, 대명사, 반복어 단서 유지
4. 가능한 순서 조합 제시

블록 기능:

- 도입
- 문제 제기
- 원인
- 사례
- 반전
- 결론

나쁜 분할:

- 아무 문장이나 기계적으로 자름
- 각 블록이 독립적으로 완결됨
- 연결 단서가 없음

### 6.9 어색한 문장

측정:

- 문단 통일성
- 논리 흐름
- 문장 기능 파악

좋은 어색한 문장:

- 소재는 비슷함
- 논리 방향은 어긋남
- 전후 연결을 깨뜨림

나쁜 어색한 문장:

- 너무 노골적으로 동떨어짐
- 다른 문장도 어색해 보임
- 정답 근거가 느낌뿐임

### 6.10 일치/불일치

측정:

- 세부 정보
- 조건
- 수치
- 시간

- 수치 변경
- 원인/결과 뒤집기
- 정도 표현 조작
- 예외를 일반화

금지:

- 지문 밖 정보로만 오답 만들기
- 너무 사소한 함정
- 정답 선지만 정보량이 다름

### 6.11 요약문 완성

측정:

- 핵심 정보 압축
- 논리 구조 재구성

절차:

1. 지문을 1~2문장 요약
2. 핵심어 1~2개 빈칸 처리
3. 정답은 원문어 또는 패러프레이즈
4. 오답은 범위, 초점, 논리관계를 비틂

## 7. 선지 제작 로직

```text
1. 정답을 먼저 쓴다.

6. 정답번호를 재배치한다.
7. 이상 패턴을 필터링한다.
```

### 7.2 오답 DNA

| 조건 누락 | 중요한 조건을 빼고 일반화 |
| 지시어 혼동 | 대명사/지시어 대상을 잘못 연결 |
| 세부정보 혼동 | 수치, 주체, 시간 등을 바꿈 |

### 7.3 좋은 선지 조건

- 다섯 선지 길이가 비슷함
- 모든 선지가 본문과 어느 정도 연결됨
- 오답도 학생이 고민할 만함
- 정답만 유독 구체적이지 않음
- 선지 간 범주가 겹치지 않음
- 한국어가 자연스러움
- 학생용 선지에 제작자 메타 표현이 없음

## 8. 서술형 출제 로직

### 8.1 서술형 중심 방향

강화:

- 주제문 쓰기
- 내용 이해
- 핵심문장 복원
- 어법 오류 수정
- 인터뷰형 답변 완성
- 삽화 기반 설명

축소:

- 단순 구문변환
- 힌트 없는 자유영작
- 지나치게 긴 영작
- 고1 수준을 넘는 추상적 영작

### 8.2 조건부 영작 기본 요소

기본 제공:

- 한국어 뜻
- 단어 수
- 사용할 단어
- 어형 변화 가능 여부
- 필요한 경우 첫 단어
- 첫 단어만 부족하면 주어 또는 시작구

### 8.3 힌트 사다리

| 단계 | 제공 정보 | 사용 상황 |
|---|---|---|
| H0 | 힌트 거의 없음 | 쉬운 단답 |
| H1 | 한국어 뜻 | 기본 영작 |
| H2 | 한국어 뜻 + 필수어 | 표준 조건부 영작 |
| H3 | 한국어 뜻 + 필수어 + 단어 수 | 일반 내신형 |
| H4 | H3 + 첫 단어 | 문장 구조가 조금 어려움 |
| H5 | H3 + 주어/시작구 | 첫 단어만으로 불가능 |

### 8.4 힌트 제공 규칙

- 한국어 뜻을 주지 않으면 단어 힌트를 더 많이 준다.
- 한국어 뜻을 주면 단어 힌트는 조금 줄일 수 있다.
- 첫 단어만으로 답을 쓰기 어려우면 주어를 준다.
- 조건 단어가 주어와 겹치면 주어 대신 다른 핵심어를 준다.
- 문장 구조가 복잡하면 접속사나 시작구를 제공한다.
- 정답을 먼저 만든 뒤 단어 수를 정확히 센다.

### 8.5 단어 수 산정

절차:

```text
1. 모범답안 작성
2. 단어 수 계산
3. 조건에 단어 수 반영
4. 허용 답안이 있으면 범위 제시
5. 채점 기준 작성
```

예:

```text
모범답안:
Social conditions shape how people experience beauty from early life.

단어 수:
9 words
```

### 8.6 어법 교정 서술형

대표 형식:

```text
다음 글에서 어법상 틀린 곳 7개 중 4개를 찾아 바르게 고쳐 쓰시오.
```

설계:

- 오류 7개 삽입
- 학생은 4개만 수정
- 오류는 고1 수준
- 같은 문법 포인트 반복 금지
- 답안란은 한 문항당 하나

오류 후보:

- 수일치
- 시제
- 능동/수동
- 관계사
- 분사
- 병렬
- 준동사
- 비교
- 접속사/전치사

### 8.7 주제문 서술형

대표 발문:

```text
다음 글의 핵심 내용을 12단어 이내의 영어 한 문장으로 쓰시오.
```

```text
주어진 단어를 모두 활용하여 글의 주제를 영어 한 문장으로 쓰시오.
```

```text
인터뷰 질문에 대한 답이 되도록 글의 중심 내용을 영어 한 문장으로 쓰시오.
```

필수:

- 모범답안
- 단어 수
- 필수어
- 허용 답안
- 채점 기준

## 9. 삽화·인터뷰형 로직

### 9.1 삽화형

삽화는 장식이 아니라 문제 상황을 시각화하는 보조 자료다.

사용 가능:

- 인터뷰 장면
- 실험/관찰 장면
- 두 개념의 대립
- 과정 흐름
- 사회적 상황

주의:

- 삽화만 보고 답이 나오면 안 됨
- 흑백 인쇄에서도 알아볼 수 있어야 함
- 지문보다 더 많은 정보를 주면 안 됨

### 9.2 인터뷰형

본문 내용을 다른 담화 상황으로 바꾸는 유형.

가능 유형:

- 기자와 전문가 인터뷰
- 학생 발표 후 질의응답
- 팟캐스트 대화
- 상담 장면
- 토론 후 요약

문항:

- 답변 완성
- 질문 의도 파악
- 인터뷰 내용 일치/불일치
- 핵심 주장 한 문장 작성

```text
어린 시절의 경험과 사회적 조건이 개인의 미적 취향을 형성한다는
```

### 10.3 오답 해설 작성

나쁜 예:

```text
본문과 다르므로 오답이다.
```

좋은 예:

```text
②는 본문 앞부분의 개인적 경험이라는 소재와 연결되지만,
그 경험이 사회적 조건에 의해 형성된다는 결론을 놓치고 있어 오답이다.
```

### 10.4 어휘 정리

형식:

```text
determination n. 규정 요인, 결정 요인
- 문맥상 의미: 개인의 경험을 형성하는 사회적 조건
- 주의: '결심'으로 해석하면 문맥이 어긋남
- 출제 포인트: social determinations = 사회적 규정 요인
```

### 10.5 구문 정리

형식:

```text
원문:
The analysis of this relation must go back to the earliest stage of a child's life.

구조:
주어 The analysis of this relation
동사 must go back
전치사구 to the earliest stage...

해석:
이 관계에 대한 분석은 아이의 삶의 가장 초기 단계로 거슬러 올라가야 한다.

포인트:
go back to는 물리적 이동이 아니라 분석의 출발점을 뜻한다.
```

### 10.6 배경지식

원칙:

- 처음 등장할 때만 자세히 설명
- 반복되는 배경지식은 간단히 처리
- 문제 풀이에 필요한 정도만 제공
- 배경지식이 정답 판단의 필수 조건이 되면 안 됨

## 11. 문제은행 조립 로직

### 11.1 생성 흐름

```text
자료 수집

→ 지문 정규화
→ 출제 포인트 분석

→ 최종 검수
```

### 11.2 문항 배치

문제은행:

- 유형을 적절히 섞는다.
- 같은 출처가 연속되지 않게 한다.
- 같은 유형이 과도하게 몰리지 않게 한다.
- 서술형이 한쪽에 몰리지 않게 한다.
- 지문 길이를 고려해 페이지 흐름을 잡는다.

동형모고 26문항:

```text
1~5: 내용 이해, 주제, 요지, 제목
6~10: 일치/불일치, 어휘
11~15: 빈칸, 삽입, 순서
16~20: 어법, 어색한 문장, 요약
21~26: 서술형, 복합형, 변별 문항
```

실제 조립에서는 지문 길이와 난이도 리듬을 고려해 조정한다.

## 19. 운영 결론

Ray's Drill의 출제 로직은 다음 순서로 압축된다.

```text
원문 보존
→ 변형 단계 선택
→ 지문 안에 유형 조작 반영
→ 한 지문당 1~3문항 생성
→ 기능적 오답 설계
→ 서술형 힌트 현실화
→ 정답번호 균형화
→ 해설 확장
→ 2단 시험지 조판
→ 하네스 전수검수
→ 배부 가능한 문항만 최종본에 반영
```

최종 원칙:

```text
많이 만들되, 이상한 문제는 남기지 않는다.
지문은 줄이지 않되, 문제 유형에 맞게 정직하게 조작한다.
선지는 학생이 고민할 만큼 매력적이어야 하고,
서술형은 학생이 실제로 쓸 수 있을 만큼 친절해야 한다.
```
