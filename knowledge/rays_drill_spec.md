# Ray's Drill 출제방식 상세 규격서

본 문서는 이 채팅에서 누적 확정된 Ray's Drill 문제 제작 방식을 최대한 상세하게 정리한 제작 규격서이다.  
목표는 “매번 감으로 문제를 만드는 것”이 아니라, 어떤 영어 지문이 들어와도 일정한 품질로 문제은행·실전형 시험지·정답해설지를 생산할 수 있는 출제 파이프라인을 고정하는 것이다.

---

## 0. 문서의 목적

이 문서는 다음 작업에 재사용된다.

- 수특라이트 기반 문제은행 제작
- 교과서 본문 기반 내신 대비 문제 제작
- 모의고사 지문 기반 수능형 변형 문제 제작
- Ray's 동형모고 26문항 세트 조립
- DOCX/PDF 시험지 조판
- 정답·해설지 제작
- Claude/Codex 간 상호 검수
- 문제은행 제작 하네스 자동화

이 문서의 핵심은 다음 네 가지이다.

1. 지문을 어떻게 가공할 것인가
2. 문항을 어떤 유형으로 만들 것인가
3. 선지와 서술형 조건을 어떻게 설계할 것인가
4. 완성본을 어떤 기준으로 검수할 것인가

---

## 1. Ray's Drill의 정체성

Ray's Drill은 단순한 샘플 문제지가 아니다.  
실제 학교 내신 대비를 위해 학생에게 배포 가능한 문제은행형 실전 자료이다.

### 1.1 기본 대상

- 학년: 고등학교 1학년
- 과목: 영어
- 목적: 내신 대비, 기말고사 대비, 실전형 드릴
- 난이도: 기본은 표준 난이도이나, 품질 보존을 위해 필요하면 난이도 상승 허용
- 형식: 실제 학교 시험지와 유사한 문항 구성, 2단 조판, 객관식·서술형 혼합

### 1.2 제작물 종류

Ray's Drill 산출물은 크게 두 계열로 나뉜다.

| 구분 | 설명 |
|---|---|
| 문제은행형 | 가능한 많은 문항을 만들고, 학생이 반복 훈련할 수 있도록 유형별·난이도별로 축적 |
| 동형모고형 | 문제은행에서 26문항 단위로 선별하여 실제 시험처럼 조립 |

### 1.3 문제은행형의 원칙

- 문항 수를 최대한 많이 만든다.
- 단, 선지 품질이 무너지면 수량을 포기한다.
- 한 지문에 문항을 과도하게 몰지 않는다.
- 같은 지문에서 나온 문제끼리 서로 답을 노출하지 않도록 한다.
- 같은 출처, 같은 유형, 같은 정답번호가 연속적으로 몰리지 않도록 한다.

### 1.4 동형모고형의 원칙

- 26문항을 한 세트로 구성한다.
- 객관식과 서술형을 실제 학교 시험처럼 섞는다.
- 지문 출처와 유형이 한쪽으로 몰리지 않게 한다.
- 난이도는 표준 내신 수준을 기본으로 하되, 상위권 변별 문항을 일부 포함한다.

## 2. 자료 사용 원칙

### 2.1 자료의 역할 구분

| 자료 | 역할 |
|---|---|
| 수특라이트 | 주요 문제은행 원천 지문 |
| 교과서 본문 | 학교 내신형 내용 이해·어법·서술형 강화 |
| 교과서 대화문 | 대화 흐름·응답 완성·상황 이해형 문항 제작 |
| 모의고사 지문 | 수능형 유형 확장 |
| 학교 기출모음 | 실제 내신 스타일, 선지 길이, 서술형 조건, 조판 밀도 학습 |
| 프롬프트 TXT | 유형별 문항 제작 방식 참고 |
| 단어장·숙어집 | 난이도 조절, 해설 어휘 보강, 서술형 힌트 구성 |
| 구문 자료 | 서술형·어법·구문 포인트 해설 보강 |

### 2.2 참고 자료 사용 방식

참고 자료의 문항을 그대로 베끼지 않는다.  
참고할 것은 다음이다.

- 문제 발문 방식
- 지문 변형 방식
- 선지 구성 밀도
- 오답의 매력도
- 서술형 힌트 제공 방식
- 해설지의 정보 배치
- 시험지 조판 감각

### 2.3 실제 출제 대상

문제는 항상 사용자가 지정한 본문 범위에서 만든다.

예시:

- 수특라이트 04·05·07강 Gateway 제외
- 특정 강의 3번·4번 지문
- NE능률 민병천 3·4과 본문
- YBM 김은형 3·4과
- 2026년 3월 고1 모의고사 특정 번호
- 2025년 6월 고1 모의고사 특정 번호

## 3. 지문 처리 절대 원칙

### 3.1 지문을 줄이지 않는다

사용자의 가장 강한 요구사항은 다음이다.

> 지문은 절대로 줄여서는 안 된다. 변환은 가능하지만, 생략·중략·임의 축약은 금지한다.

따라서 다음은 금지된다.

- 긴 문장을 임의로 삭제
- 지문 중간을 `...`로 생략
- 핵심 문단만 남기고 나머지를 제거
- 문항 제작 편의를 위해 일부 정보 누락
- 학생이 읽어야 할 논리 단계를 건너뜀

### 3.2 변형은 가능하다

지문은 다음 방식으로 변형할 수 있다.

- 어휘 변형
- 구문 변형
- 문장 순서 조정
- 문장삽입용 문장 제거
- 빈칸 생성
- 어법 오류 삽입
- 주제 동일 전체 재작성
- 대화문을 인터뷰·기사·안내문 형태로 변환

단, 변형 후에도 다음은 보존해야 한다.

- 원래 주제
- 핵심 논리
- 필자의 태도
- 인과관계
- 대조관계
- 구체 사례의 기능
- 결론의 방향
- 정보량

### 3.3 “원문 그대로”와 “변형”의 균형

문제은행은 다음 네 파트로 구성한다.

| 파트 | 설명 | 목적 |
|---|---|---|
| A. 본문 무변형 | 원문을 그대로 사용 | 기본 독해, 내용 확인, 원문 친숙도 |
| B. 본문 변형: 어휘 | 단어·표현을 동의어/상위어/문맥어로 변환 | 단순 암기 방지 |
| C. 본문 변형: 구문 | 수동/능동, 관계사, 분사, 명사절 등 구조 변환 | 문장 구조 이해 확인 |
| D. 주제 동일 전체 변형 | 소재와 논리를 보존하되 새 지문으로 재작성 | 고난도 응용, 참고풀이 차단 |

### 3.4 변형의 목적

변형은 “멋있게 바꾸기”가 아니다.  
목적은 다음이다.

- 학생이 다른 문제의 지문을 보고 답을 찾지 못하게 하기
- 원문 암기만으로 풀 수 없게 하기
- 실제 시험의 변형 가능성에 대비하기
- 어휘·구문·논리 이해를 동시에 측정하기

## 4. 공통 지문 제작 원칙

### 4.1 가장 중요한 금지사항

공통 지문을 그대로 주고, 문제에서 또 별도의 조작 지문을 주면 안 된다.

잘못된 예:

```text
[공통 지문]
원문 전체를 그대로 제시한다.

[문제]
다음 문장이 들어갈 위치로 알맞은 곳은?
```

이 경우 학생은 공통 지문 속에 이미 들어 있는 문장을 보고 답을 찾을 수 있다.  
이것은 문장삽입 문제가 아니라 정답 노출이다.

### 4.2 올바른 방식

문제 유형의 조작은 반드시 공통 지문 안에 반영한다.

| 유형 | 공통 지문 반영 방식 |
|---|---|
| 문장삽입 | 삽입할 문장을 실제로 지문에서 제거하고 위치 표시 삽입 |
| 빈칸 | 정답 부분을 실제로 빈칸 처리 |
| 어법 | 밑줄 또는 선택지 지점을 실제 지문 안에 표시 |
| 어색한 문장 | 흐름을 깨는 문장을 실제 지문 안에 삽입 |
| 글의 순서 | 문단/문장 블록을 실제로 분리하여 제시 |
| 요약문 | 지문은 유지하고 요약문에서 핵심어 빈칸 처리 |
| 일치/불일치 | 지문은 유지하되 선지가 세부정보를 정확히 비틀어야 함 |

### 4.3 공통 지문과 문항의 관계

공통 지문 하나에 문항을 여러 개 붙일 수는 있다.  
다만 다음 조건을 지켜야 한다.

- 한 지문당 1~3문항
- 문항들이 서로 답을 노출하지 않음
- 문항별 조작 지점이 충돌하지 않음
- 공통 지문 하나로 모든 문제가 자연스럽게 풀림
- 별도 문제용 지문을 중복 제공하지 않음

## 5. 한 지문당 문항 수

### 5.1 기본 규칙

한 지문당 문항 수는 1개, 2개, 3개 중에서 배정한다.

- 1문항: 짧거나 논점이 하나인 지문
- 2문항: 내용 이해 + 어법/어휘 정도가 가능한 지문
- 3문항: 논리 구조가 풍부하고 변형 가능성이 높은 지문

### 5.2 금지

- 모든 지문을 무조건 3문항으로 만들기
- 한 지문에 4문항 이상 몰아넣기
- 같은 지문에서 나온 앞 문제의 선지가 뒤 문제의 힌트가 되게 하기
- 같은 공통 지문으로 빈칸·삽입·순서 조작을 동시에 무리하게 넣기

### 5.3 문제은행과 모의고사 차이

문제은행에서는 많은 문항을 만들 수 있다.  
그러나 한 지문에 몰아넣는 것이 아니라, 같은 원천 지문을 여러 변형 버전으로 나누어 출제한다.

예시:

- 04강 1번 원문 버전: 내용일치 1문항
- 04강 1번 어휘 변형 버전: 빈칸 1문항
- 04강 1번 구문 변형 버전: 어법 1문항
- 04강 1번 전체 변형 버전: 주제문 서술형 1문항

이렇게 하면 지문당 문항 과밀을 피하면서도 문제은행 규모를 키울 수 있다.

## 7. 객관식 유형별 제작법

### 7.1 주제 유형

#### 측정 능력

- 글 전체의 핵심 논지 파악
- 사례와 결론의 위계 구분
- 반복 키워드와 중심 주장 연결

#### 발문 예시

```text
다음 글의 주제로 가장 적절한 것은?
다음 글의 중심 내용으로 가장 적절한 것은?
```

#### 정답 설계

정답은 다음 특성을 가져야 한다.

- 글 전체를 포괄
- 너무 넓지도 좁지도 않음
- 필자의 결론 방향 반영
- 사례가 아니라 일반화된 핵심 진술

#### 오답 설계

좋은 오답은 다음 중 하나를 활용한다.

- 본문 사례 하나만 일반화
- 원인과 결과를 뒤집음
- 핵심 대비를 약화
- 필자의 주장을 중립 정보로 바꿈
- 글의 일부 키워드는 포함하지만 결론 방향이 다름

#### 금지 오답

- 글 밖 상식으로만 판단 가능한 선지
- 본문 키워드만 랜덤 조합한 선지
- 지나치게 터무니없는 선지
- “본문은 ~라고 말한다” 식의 메타 선지

---

### 7.2 제목 유형

#### 측정 능력

- 핵심 주제를 압축적으로 표현하는 능력
- 글의 초점과 분위기 파악

#### 발문 예시

```text
다음 글의 제목으로 가장 적절한 것은?
```

#### 정답 설계

- 핵심 주제를 압축
- 너무 설명문처럼 길지 않음
- 소재와 주장 모두 반영
- 과장된 표현 피함

#### 오답 설계

- 소재만 맞고 주장 빠짐
- 주장 방향 반대
- 너무 세부적
- 너무 넓음
- 본문에 없는 가치판단 추가

---

### 7.3 요지 유형

#### 측정 능력

- 필자가 궁극적으로 말하려는 바 파악
- 근거와 결론의 관계 이해

#### 발문 예시

```text
다음 글의 요지로 가장 적절한 것은?
```

#### 정답 설계

- “그래서 무엇을 말하려는가?”에 답해야 한다.
- 단순 주제보다 주장성이 조금 더 강할 수 있다.
- 사례 설명이 아니라 결론 문장이어야 한다.

---

### 7.4 주장 유형

#### 측정 능력

- 필자의 권고, 판단, 당위 파악

#### 발문 예시

```text
다음 글에서 필자가 주장하는 바로 가장 적절한 것은?
```

#### 정답 설계

- 해야 한다/필요하다/중요하다의 방향이 살아 있어야 한다.
- 단순 사실 설명이면 주장 유형에 부적합하다.

#### 주의

원문이 설명문이면 억지로 주장 유형으로 만들지 않는다.  
주장성이 약한 지문은 주제·요지·제목 유형이 더 적합하다.

### 7.6 빈칸 유형

#### 측정 능력

- 문맥 추론
- 앞뒤 논리 연결
- 핵심 개념 복원

#### 빈칸 위치

좋은 빈칸 위치:

- 결론부 핵심어
- 대조 뒤 전환점
- 인과관계의 결과
- 예시를 일반화하는 문장
- 글 전체 주제를 압축하는 표현

나쁜 빈칸 위치:

- 단순 고유명사
- 사소한 세부정보
- 앞 문장에 그대로 반복된 단어
- 문법만 맞추면 되는 자리

#### 선지 설계

정답:

- 앞뒤 문맥에 필연적으로 맞아야 함
- 글 전체 논리와 연결

오답:

- 문법적으로는 들어갈 수 있음
- 키워드는 일부 맞음
- 논리 방향이 다름
- 범위가 너무 넓거나 좁음

---

### 7.7 문장삽입 유형

#### 절대 조건

삽입할 문장은 반드시 원 지문에서 제거되어야 한다.  
원문을 그대로 주고 문장삽입을 물으면 안 된다.

#### 제작 절차

1. 원문에서 응집성이 강한 문장을 선택한다.
2. 해당 문장을 제거한다.
3. 남은 지문에 위치 표시를 넣는다.
4. 제거된 문장을 `[주어진 문장]`으로 제시한다.
5. 지시어, 연결어, 반복어, 인과관계를 근거로 정답 위치를 정한다.

#### 좋은 삽입 문장의 특징

- this, these, such, however, therefore 등 연결 단서가 있음
- 앞 문장의 정보를 받아야 함
- 뒤 문장의 예시나 결론으로 이어짐
- 아무 데나 들어갈 수 없음

#### 오답 위치 설계

- 앞뒤 한쪽만 그럴듯한 위치
- 지시어 선행사가 없는 위치
- 대조 연결이 어색한 위치
- 예시와 일반화 순서가 뒤집히는 위치

---

### 7.8 글의 순서 유형

#### 측정 능력

- 문단 간 논리 순서 파악
- 도입-전개-반전-결론 구조 이해

#### 제작 절차

1. 지문을 3개 블록으로 나눈다.
2. 각 블록이 독립적으로 너무 완결되지 않도록 한다.
3. 연결어·대명사·반복어 단서가 남도록 한다.
4. 가능한 순서 조합을 선지로 제시한다.

#### 좋은 블록 분할

- A: 문제 제기
- B: 근거 또는 사례
- C: 결론 또는 전환

#### 나쁜 블록 분할

- 아무 문장이나 기계적으로 자름
- 각 블록 첫 문장이 모두 독립적이라 순서 단서가 없음
- 원문 순서 암기 외에는 풀 수 없음

---

### 7.9 어색한 문장 유형

#### 측정 능력

- 문단 통일성 파악
- 논리 흐름에서 벗어난 문장 식별

#### 제작 절차

1. 원 지문의 주제와 논리 흐름을 확정한다.
2. 겉보기 소재는 비슷하지만 기능이 다른 문장을 삽입한다.
3. 삽입 문장은 너무 노골적으로 동떨어지면 안 된다.
4. 정답 근거는 전후 문장의 연결 붕괴여야 한다.

#### 좋은 오답

- 모두 본문 흐름 안에서 필요한 기능을 갖는 문장
- 사례, 원인, 결과, 재진술 등 각자의 역할이 분명함

---

### 7.10 일치/불일치 유형

#### 측정 능력

- 세부 정보 확인
- 수치, 인물, 원인, 결과, 조건, 시간 관계 파악

#### 선지 설계

정답 또는 오답 변형 방식:

- 수치 변경
- 시간 순서 변경
- 원인과 결과 뒤집기
- 대상 바꾸기
- 조건 누락
- 정도 표현 바꾸기
- always/sometimes 같은 빈도 표현 조작

#### 금지

- 지문에 없는 내용으로만 선지 만들기
- 너무 사소한 철자 수준의 함정
- 선지 길이가 정답만 유독 길거나 짧음

---

### 7.11 요약문 완성 유형

#### 측정 능력

- 핵심 구조 압축
- 원문 정보를 다른 표현으로 재구성

#### 제작 절차

1. 지문을 한 문장 또는 두 문장으로 요약한다.
2. 핵심 개념 1~2개를 빈칸으로 만든다.
3. 정답은 원문 단어 그대로일 수도 있고 패러프레이즈일 수도 있다.
4. 오답은 의미 범위, 논리관계, 초점을 비튼다.

## 8. 서술형 제작 규격

서술형은 이 채팅에서 여러 차례 강하게 조정된 영역이다.  
핵심은 “학생이 실제로 쓸 수 있게 만들 것”이다.

### 8.1 서술형의 중심 방향

서술형은 다음 중심으로 출제한다.

- 주제문 작성
- 내용 이해
- 핵심문장 복원
- 어법 오류 수정
- 조건부 영작
- 인터뷰형 답변 완성

다음은 줄인다.

- 단순 구문변환만 요구하는 문제
- 너무 긴 영작
- 힌트가 거의 없는 자유영작
- 고1 수준을 넘어서는 추상 영작

### 8.2 조건부 영작 기본 제공 요소

조건부 서술형에는 기본적으로 다음을 제공한다.

- 한국어 뜻
- 단어 수
- 사용할 단어
- 어형 변화 가능 여부
- 필요한 경우 첫 단어
- 첫 단어만으로 부족하면 주어

### 8.3 힌트 제공 규칙

| 상황 | 힌트 제공 방식 |
|---|---|
| 한국어 뜻 제공 | 단어 힌트는 조금 적어도 됨 |
| 한국어 뜻 미제공 | 단어 힌트를 더 많이 제공 |
| 첫 단어만 주면 불가능 | 주어 제공 |
| 조건 단어가 주어와 겹침 | 주어 대신 다른 핵심어 제공 |
| 문장 구조가 복잡함 | 접속사, 동사, 핵심 명사 제공 |
| 추론형 주제문 작성 | 키워드와 문장 시작부를 충분히 제공 |

### 8.4 단어 수 산정

단어 수는 문제를 먼저 만들고 추정하면 안 된다.  
반드시 정답을 먼저 만든 뒤 정확히 센다.

절차:

1. 모범답안을 먼저 작성한다.
2. contraction, 하이픈, 구두점 처리 기준을 정한다.
3. 단어 수를 센다.
4. 문제 조건에 단어 수를 반영한다.
5. 허용 답안이 여러 개이면 범위를 제시한다.

예시:

```text
조건: 10단어로 쓰시오.
정답: Social experiences shape what people come to regard as beautiful.
단어 수: 10
```

### 8.5 첫 단어/주어 제공 기준

너무 어려운 조건부 영작에는 첫 단어만 주는 것이 부족하다.

나쁜 조건:

```text
조건: 8단어, reopen, ticket offices, staff를 모두 사용할 것.
첫 단어: The
```

이 경우 학생은 주어 구조를 잡기 어렵다.

개선:

```text
조건: 8단어, reopen, ticket offices, staff를 모두 사용할 것.
주어: The theater
```

또는:

```text
조건: 8단어, reopen, ticket offices, staff를 모두 사용할 것.
시작: The theater should
```

### 8.6 어법 교정 서술형

어법 서술형은 특히 강화한다.

대표 유형:

```text
다음 글에서 어법상 틀린 곳 7개 중 4개를 찾아 바르게 고쳐 쓰시오.
```

#### 구성 기준

- 오류는 7개 정도 삽입
- 학생은 4개만 고치게 하여 부담 조절
- 각 오류는 고1 수준 문법 포인트여야 함
- 같은 문법 포인트만 반복하지 않음
- 답안란은 한 문항에 하나만 둠

#### 오류 후보

- 주어-동사 수일치
- 시제 불일치
- 능동/수동 혼동
- 관계대명사/관계부사
- 분사 현재/과거
- 병렬구조
- 비교급/최상급
- 접속사/전치사 혼동
- 동명사/부정사
- 명사절 접속사

### 8.7 주제문 서술형

사용자가 최종적으로 강조한 방향은 다음이다.

> 서술형은 내용이해·어법·주제문 중심. 구문변환 같은 건 내지 말 것.

따라서 주제문 서술형을 강화한다.

#### 좋은 발문

```text
다음 글의 핵심 내용을 12단어 이내의 영어 한 문장으로 쓰시오.
```

```text
다음 글의 주제를 드러내도록 주어진 단어를 모두 활용하여 영어 한 문장으로 쓰시오.
```

```text
인터뷰 질문에 대한 답이 되도록, 글의 중심 내용을 영어 한 문장으로 쓰시오.
```

#### 힌트 예시

```text
조건
1. 11단어로 쓸 것
2. experience, society, shape를 반드시 사용할 것
3. 필요한 경우 어형 변화 가능
4. 주어는 Social conditions로 시작할 것
```

## 9. 선지 제작 상세 규격

이 채팅에서 가장 많이 문제 제기된 부분이 선지 품질이다.  
따라서 선지는 별도 품질 규격을 적용한다.

### 9.1 나쁜 선지의 특징

다음 선지는 제거 대상이다.

- “본문은 ~라고 말한다” 식의 메타 문장
- “글은 ~만으로 전체 결론이 충분히 설명된다고 본다” 식의 범용 패딩
- “사전적 의미”, “문자적 뜻”, “원문보다 넓게 일반화” 같은 템플릿 선지
- 본문과 거의 관계없는 허무맹랑한 선지
- 정답만 지나치게 길고 구체적인 선지
- 오답만 지나치게 짧은 선지
- 일부만 읽어도 바로 제거되는 선지
- `...`, `NaN`, `undefined`, 깨진 문자 포함 선지
- 문법적으로 어색한 한국어
- 학생이 무엇을 판단해야 하는지 불명확한 선지

### 9.2 좋은 선지의 기준

좋은 선지는 다음 조건을 만족한다.

- 다섯 선지의 길이가 대체로 비슷하다.
- 모든 선지가 본문과 어느 정도 연결된다.
- 오답은 본문 일부를 근거로 착각할 수 있다.
- 정답은 글 전체 논리와 가장 정확히 맞는다.
- 선지 간 범주가 겹치지 않는다.
- 선지 하나만 문체가 다르지 않다.
- 정답이 항상 가장 추상적이거나 가장 긴 형태로 드러나지 않는다.

### 9.3 매력적인 오답 설계법

매력적인 오답은 틀렸지만 “왜 틀렸는지 설명 가능한” 오답이다.

#### 9.3.1 부분 참/전체 거짓

본문의 일부 정보는 맞지만 전체 결론은 틀린 선지.

```text
본문 일부: 어린 시절 경험이 취향 형성에 영향을 준다.
오답: 어린 시절 경험만이 모든 문학적 판단을 결정한다.
```

#### 9.3.2 인과관계 뒤집기

원인과 결과를 바꾸는 방식.

```text
정답 방향: 사회적 조건이 개인의 미적 경험을 형성한다.
오답 방향: 개인의 미적 경험이 사회적 조건을 완전히 결정한다.
```

#### 9.3.3 범위 과잉 일반화

본문의 제한된 주장을 절대 명제로 바꿈.

```text
본문: 취향은 사회적 조건의 영향을 받는다.
오답: 모든 취향은 개인 선택과 무관하게 사회가 완전히 결정한다.
```

#### 9.3.4 초점 이동

핵심 논점이 아니라 주변 소재를 중심으로 만듦.

```text
본문 핵심: 사회적 조건과 미적 경험의 관계
오답: 작가의 개인사가 문학 작품의 유일한 소재가 되는 과정
```

#### 9.3.5 태도 왜곡

필자의 태도나 강도를 바꿈.

```text
본문: 영향을 받는다.
오답: 완전히 지배된다 / 전혀 관련 없다.
```

### 9.4 선지 길이 규칙

선지 길이는 다음 범위를 권장한다.

- 주제/요지/제목: 선지 간 길이 차이 1.5배 이내
- 일치/불일치: 정보량을 비슷하게 유지
- 빈칸: 품사와 문장 구조가 모두 들어맞게 유지
- 어법: 선택지 길이를 억지로 맞추기보다 문법 포인트 명확성 우선

### 9.5 정답번호 배치

정답번호는 교육평가적 단서가 되면 안 된다.

규칙:

- ①~⑤ 분포를 최대한 균등화
- 같은 정답번호 3연속 금지
- 같은 지문·같은 유형·같은 정답번호 반복 회피
- 마지막 선지가 계속 정답이 되는 패턴 회피
- 어려운 문항만 ④·⑤에 몰리는 패턴 회피

---

## 10. 지문 변형 상세 규격

### 10.1 어휘 변형

어휘 변형은 원문 암기를 무력화하기 위한 장치이다.

#### 변형 가능 요소

- 동의어
- 반의어 구조 전환
- 상위어/하위어
- 구동사/단일동사 전환
- 형용사구/관계절 전환
- 추상명사/동사 표현 전환

#### 예시

```text
원문: influence
변형: shape, affect, condition, guide
```

```text
원문: subjective aesthetic experience
변형: personal sense of beauty
```

### 10.2 구문 변형

구문 변형은 의미를 유지하면서 표면 구조를 바꾸는 것이다.

#### 변형 방식

- 능동 ↔ 수동
- 관계절 ↔ 분사구
- 부사절 ↔ 전치사구
- 명사절 ↔ 동명사구
- 강조구문
- 도치
- 병렬구조 재배열
- 삽입구 처리

#### 주의

구문 변형 자체를 서술형으로 묻는 문제는 줄인다.  
단, 객관식 어법·독해 지문 변형에는 사용할 수 있다.

### 10.3 주제 동일 전체 변형

가장 강한 변형 방식이다.

#### 원칙

- 원문의 주제와 논리 구조는 유지
- 문장과 표현은 새로 작성
- 사례를 유사하지만 다른 사례로 바꿀 수 있음
- 학생이 원문 문장 암기로 풀 수 없게 함

#### 금지

- 원문의 핵심 주장 왜곡
- 정보량 축소
- 새로운 배경지식 과잉 추가
- 원문보다 훨씬 어려운 학술문으로 변질

## 11. 삽화·인터뷰형 문항

### 11.1 삽화형 문항

삽화는 시험지를 다양하게 만들기 위한 장치이다.  
그러나 삽화가 답을 직접 알려주면 안 된다.

#### 용도

- 상황 이해
- 인터뷰 장면 제시
- 실험/사례 시각화
- 글의 핵심 대립 구조 표현
- 학생 흥미 유발

#### 제작 기준

- 흑백 인쇄에서도 구분 가능
- 지나치게 장식적이지 않음
- 문제 풀이에 필요한 정보만 포함
- 영어 지문보다 삽화가 더 많은 정보를 주지 않음

### 11.2 인터뷰형 문항

본문 내용을 다른 담화 상황으로 바꾸는 유형이다.

#### 예시 유형

- 기자와 전문가 인터뷰
- 학생 발표 후 질의응답
- 팟캐스트 대화
- 상담 장면
- 토론 후 요약

#### 출제 가능 문항

- 인터뷰 답변 완성
- 질문 의도 파악
- 답변 내용 일치/불일치
- 핵심 주장 한 문장 작성
- 빈칸 대화 완성

## 12. 해설지 제작 규격

해설지는 단순 정답표가 아니다.  
학생이 혼자 복습할 수 있는 분석 자료여야 한다.

### 12.1 문항별 필수 요소

각 문항 해설에는 다음을 넣는다.

- 정답
- 출제의도
- 정답 근거
- 오답 분석
- 지문 해석
- 핵심 어휘
- 주요 구문
- 키포인트
- 배경지식

### 12.2 출제의도

출제의도는 “무엇을 평가하려는 문항인가”를 명확히 쓴다.

나쁜 예:

```text
본문 이해 여부를 묻는 문제이다.
```

좋은 예:

```text
사회적 조건이 개인의 미적 경험을 형성한다는 글의 핵심 논지를,
어린 시절 경험과 계급적 배경의 관계를 통해 파악하는지 평가한다.
```

### 12.3 오답 해설

오답 해설은 단순히 “본문과 다르다”라고 쓰지 않는다.

각 오답에 대해 다음 중 하나를 설명한다.

- 어느 부분은 맞지만 왜 결론이 틀렸는지
- 어떤 인과관계를 뒤집었는지
- 어떤 범위를 과장했는지
- 어떤 세부정보를 혼동했는지
- 본문에 없는 내용을 추가했는지

### 12.4 어휘 정리

어휘는 단어 뜻만 나열하지 않는다.

포함 요소:

- 단어
- 품사
- 뜻
- 문맥상 의미
- 유의어/반의어
- 출제 포인트

예시:

```text
determination n. 결정 요인, 규정성
- 이 지문에서는 개인의 경험을 형성하는 사회적 조건이라는 의미
- 단순한 '결심'이 아님
```

### 12.5 구문 정리

구문은 학생이 해석에 막힐 만한 문장 위주로 정리한다.

포함 요소:

- 원문 문장
- 구조 분석
- 해석
- 문법 포인트
- 출제 가능성

### 12.6 배경지식

배경지식은 중복을 피한다.

규칙:

- 처음 등장하는 개념은 자세히 설명
- 이후 반복되는 개념은 짧게 언급
- 문제 풀이에 필요한 정도만 제공
- 지문 밖 지식을 정답 판단에 요구하지 않음

## 13. DOCX/PDF 조판 규격

### 13.1 기본 형식

- DOCX 우선 제작
- 필요 시 PDF 변환
- 실제 학교 시험지 느낌
- 한 면 2단 구성
- 문제지와 해설지 분리

### 13.2 페이지 구성

권장 설정:

- 용지: B4 또는 A4, 상황에 따라 선택
- 방향: 세로
- 단: 2단
- 문항 간 여백 충분히 확보
- 지문과 선지 사이 여백 확보
- 서술형 답안란은 한 문항당 하나

### 13.3 가독성 기준

금지:

- 문제 사이가 너무 촘촘함
- 선지가 줄줄 붙어 있음
- 지문이 페이지 끝에서 잘림
- 문단 시작마다 불필요한 글머리표가 붙음
- 깨진 문자 또는 이상 기호가 남음
- 답안란이 3개씩 중복 생성됨

### 13.4 실제 시험지 느낌

실제 시험지처럼 보이려면 다음을 지킨다.

- 문항 번호는 명확하게
- 지문 박스 또는 들여쓰기 일관성 유지
- 선지는 ①~⑤ 형태
- 서술형은 답안란을 충분히 확보
- 긴 지문은 단 사이에서 자연스럽게 흐르게 함
- 지문과 문제 사이의 시각적 계층을 분명히 함

## 14. 문제은행 제작 파이프라인

### 14.1 전체 흐름

```text
자료 수집
→ 지문 추출
→ 지문 정규화
→ 출제 가능 포인트 분석
→ 변형 버전 생성
→ 유형 배정
→ 문항 초안 생성
→ 선지 정비
→ 서술형 조건 검수
→ 정답번호 재배치
→ 해설 확장
→ DOCX 조판
→ 품질 검수
→ 배부용 완성본 저장
```

### 14.2 단계별 상세

#### 1단계: 자료 수집

- 원문 PDF/MD/TXT 확보
- 범위 확인
- 제외 지문 확인
- 대화문 포함 여부 확인
- Gateway 제외 여부 확인

#### 2단계: 지문 추출

- 원문을 빠짐없이 추출
- 줄바꿈·하이픈·특수문자 정리
- 지문 ID 부여
- 출처 라벨 부여

#### 3단계: 출제 포인트 분석

각 지문에 대해 다음을 기록한다.

- 주제
- 핵심 주장
- 논리 구조
- 주요 어휘
- 주요 구문
- 어법 포인트
- 변형 가능 지점
- 삽입 가능 문장
- 빈칸 가능 표현
- 서술형 가능 문장

#### 4단계: 변형 버전 생성

각 지문을 다음 중 하나 이상으로 변형한다.

- 원문 그대로
- 어휘 변형
- 구문 변형
- 전체 변형

#### 5단계: 유형 배정

지문에 맞는 유형만 배정한다.

예:

- 논리 전개가 뚜렷함 → 순서, 삽입, 빈칸
- 세부정보가 많음 → 일치/불일치
- 문법 구조가 좋음 → 어법
- 핵심 주장이 선명함 → 주제, 요지, 주제문 서술형
- 사례 구조가 있음 → 어색한 문장, 요약문

#### 6단계: 문항 생성

- 공통 지문 안에 조작 반영
- 한 지문당 1~3문항
- 객관식/서술형 균형
- 같은 지문에서 답 노출 방지

#### 7단계: 선지 검수

- 범용 패딩 선지 제거
- 선지 길이 조정
- 오답 매력도 점검
- 정답 단서 제거
- 정답번호 재배치

#### 8단계: 해설 확장

- 정답 근거 명확화
- 오답별 해설 작성
- 어휘/구문 정리
- 배경지식 중복 제거

#### 9단계: 조판

- 2단 DOCX 생성
- 지문 잘림 확인
- 서술형 답안란 확인
- 문단 글머리표 제거

#### 10단계: 최종 검수

- 지문 누락 없음
- 지문 임의 축약 없음
- 문제용 별도 지문 중복 없음
- 정답 오류 없음
- 선지 품질 이상 없음
- 해설 누락 없음
- DOCX 열림 확인

## 15. 하네스 자동 검수 항목

문제은행 하네스는 다음 항목을 자동 또는 반자동으로 점검해야 한다.

### 15.1 데이터 검수

- item_id 중복 없음
- source_id 누락 없음
- question_type 누락 없음
- answer 누락 없음
- choices 개수 확인
- 서술형 문항의 model_answer 존재 확인

### 15.2 지문 검수

- common_passage 존재
- 조작 유형과 지문 반영 일치
- 삽입 문장이 지문에 그대로 남아 있지 않음
- 빈칸 정답이 지문에 노출되지 않음
- 어법 오류 위치 표시 있음
- 생략 표시 `...` 사용 금지

### 15.3 선지 검수

자동 제거 패턴:

- `본문은`
- `글은`
- `사전적`
- `문자적`
- `원문보다`
- `근거 없이`
- `글 밖`
- `undefined`
- `NaN`
- `...`
- `…`
- 깨진 문자

### 15.4 정답번호 검수

- ①~⑤ 분포 계산
- 같은 번호 3연속 여부
- 같은 출처 연속 여부
- 같은 유형 연속 여부

### 15.5 서술형 검수

- 단어 수 조건과 모범답안 일치
- 한국어 뜻 제공 여부 확인
- 힌트 충분성 확인
- 첫 단어/주어 제공 여부 확인
- 조건 단어와 주어 중복 여부 확인

### 15.6 DOCX 검수

- 파일 열림 확인
- 문단 수 확인
- 표/단 설정 확인
- 글머리표 오염 확인
- 깨진 문자 확인
- 페이지 잘림 확인

## 17. 품질 컷 기준

다음 중 하나라도 해당하면 완성본에서 제외하거나 재작성한다.

### 17.1 지문 관련

- 지문이 임의로 줄어듦
- 중략 표시가 있음
- 원문 의미가 바뀜
- 변형 후 정보량이 줄어듦
- 공통 지문과 문항 조작이 따로 놀음

### 17.2 문항 관련

- 발문이 무엇을 묻는지 불명확
- 문제 풀이에 필요한 정보가 부족
- 다른 문항을 보면 답이 노출됨
- 유형과 지문 성격이 맞지 않음
- 한 지문에 문항이 과도하게 많음

### 17.3 선지 관련

- 오답이 너무 허술함
- 정답만 길거나 구체적임
- 선지 길이가 심하게 불균형
- 범용 패딩 선지 포함
- 깨진 문자 포함
- 답이 두 개 이상 가능

### 17.4 서술형 관련

- 힌트가 부족함
- 단어 수가 틀림
- 모범답안이 없음
- 한국어 뜻/단어 조건이 불명확
- 답안란이 중복됨
- 고1 수준을 과도하게 벗어남

### 17.5 해설 관련

- 정답만 있고 근거 없음
- 오답 해설 없음
- 어휘/구문 정리 없음
- 배경지식이 반복됨
- 해석 누락

## 18. Codex 고유 스타일

Claude식 문항과 지나치게 비슷해지지 않도록 Codex는 다음 스타일을 적용한다.

### 18.1 논리 중심 변형

단순히 단어만 바꾸지 않는다.  
글의 논리 구조를 분석하여 문항을 만든다.

중점:

- 원인/결과
- 대조/양보
- 일반화/사례
- 문제/해결
- 주장/근거
- 정의/재진술

### 18.2 오답의 교육평가적 설계

오답은 랜덤하게 만들지 않는다.  
학생이 실제로 할 법한 오독을 반영한다.

오독 유형:

- 사례를 주제로 착각
- 세부정보를 결론으로 착각
- 대조 방향 반대로 이해
- 정도 표현 과장
- 필자 태도 중립화
- 원인과 결과 혼동

### 18.3 서술형 현실성 강화

서술형은 학생이 쓸 수 있게 만든다.

- 조건 명확화
- 단어 수 정확화
- 주어/첫 단어 제공
- 한국어 뜻 또는 충분한 단서 제공
- 모범답안 기반 출제

### 18.4 배부용 품질 우선

문제은행은 많이 만들되, 최종 DOCX에는 배부 가능한 문항만 남긴다.

기본 원칙:

```text
627문항을 억지로 다 넣는 것보다,
370문항이라도 선지 품질이 검수된 판을 배부한다.
```

## 19. 최종 산출물 폴더 규칙

### 19.1 완성본

완성본은 사용자가 지정한 폴더에 둔다.

예:

```text
C:\Users\이인혁\Desktop\의정부고 기말대비
```

### 19.2 제작 중간물

완성본이 아닌 자료는 Downloads의 문제은행/파이프라인 폴더에 정리한다.

예:

```text
C:\Users\이인혁\Downloads\분석지 제작\문제은행
C:\Users\이인혁\Downloads\분석지 제작\문제은행_파이프라인_하네스
```

### 19.3 파일명 규칙

권장 파일명:

```text
Ray_Drill_Bank_자료명_문제편.docx

Ray_Drill_Mock_1회_문제편.docx
```

## 20. 최종 체크리스트

완성본 제출 전 반드시 확인한다.

### 20.1 지문

- [ ] 지정 범위가 맞는가
- [ ] 제외 지문이 빠졌는가
- [ ] 지문이 줄어들지 않았는가
- [ ] 변형 후 의미가 보존되는가
- [ ] 공통 지문 안에 조작이 반영되었는가

### 20.2 문항

- [ ] 한 지문당 1~3문항인가
- [ ] 유형이 다양하게 섞였는가
- [ ] 내용이해·어법·서술형이 충분한가
- [ ] 다른 문항이 답을 노출하지 않는가

### 20.3 선지

- [ ] 선지 길이가 비슷한가
- [ ] 오답이 매력적인가
- [ ] 범용 패딩 선지가 없는가
- [ ] 정답이 두 개 이상 가능하지 않은가
- [ ] 정답번호가 몰리지 않았는가

### 20.4 서술형

- [ ] 모범답안이 먼저 만들어졌는가
- [ ] 단어 수가 정확한가
- [ ] 한국어 뜻 또는 충분한 힌트가 있는가
- [ ] 필요한 경우 주어가 제공되었는가
- [ ] 답안란이 중복되지 않는가

### 20.5 해설

- [ ] 출제의도가 있는가
- [ ] 정답 근거가 있는가
- [ ] 오답 해설이 있는가
- [ ] 어휘 정리가 있는가
- [ ] 구문 정리가 있는가
- [ ] 해석이 있는가
- [ ] 배경지식 중복이 제거되었는가

### 20.6 조판

- [ ] DOCX가 정상적으로 열리는가
- [ ] 2단 조판이 적용되었는가
- [ ] 문제 사이 여백이 충분한가
- [ ] 글이 잘리지 않는가
- [ ] 문단 앞 불필요한 글머리표가 없는가
- [ ] 깨진 문자가 없는가
