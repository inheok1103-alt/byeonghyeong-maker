대상: 고1 영어 내신 대비 자료 제작자, Codex/Claude 협업 출제 파이프라인

## 0. 이 문서의 성격

이 문서는 기존 `CHAT_출제방식_요약.md`를 계승하되, 단순 정리에서 한 단계 더 나아가 실제 출제 엔진의 설계 규격으로 발전시킨 연구판이다.

기존 문서가 “우리가 이 채팅에서 무엇을 요구했는가”를 정리했다면, 이 문서는 “그 요구를 어떤 출제 원리와 제작 공정으로 안정화할 것인가”를 정리한다.

핵심 목표는 다음이다.

- 지문을 줄이지 않으면서도 다양한 문제를 만들기
- 원문 암기형 문제가 아니라 실제 이해형 문제 만들기
- 선지를 그럴듯하고 균형 있게 만들기
- 서술형을 학생이 실제로 쓸 수 있는 난이도로 조절하기
- 문제은행형 대량 생산과 배부용 품질을 동시에 만족시키기
- Claude와 Codex가 같은 기준으로 만들고 서로 검수할 수 있게 하기

## 1. 계승할 핵심 원칙

### 1.1 지문은 줄이지 않는다

지문을 변형할 수는 있지만, 임의 축약·생략·중략은 금지한다.

허용:

- 원문 그대로 사용
- 어휘 변형
- 구문 변형
- 주제 동일 전체 변형
- 문제 유형에 필요한 조작 반영

금지:

- `...`로 중략
- 핵심 문장 삭제
- 문제 만들기 편하려고 정보량 축소
- 지문 논리 단계 생략
- 원문보다 훨씬 얕은 요약문으로 대체

### 1.2 조작은 반드시 공통 지문 안에 반영한다

문장삽입, 빈칸, 어법, 어색한 문장, 순서 유형은 문제용 조작이 공통 지문 안에 실제로 반영되어야 한다.

나쁜 방식:

```text
[공통 지문] 원문 전체를 그대로 제시
[문항] 다음 문장이 들어갈 위치는?
```

좋은 방식:

```text
[공통 지문] 삽입할 문장을 제거하고 (A)~(E) 위치 표시
[문항] 주어진 문장이 들어갈 위치는?
```

즉, 학생이 보는 지문은 항상 “그 문제를 풀 수 있도록 가공된 하나의 지문”이어야 한다.

### 1.3 문제 수보다 품질이 우선이다

문제은행형은 많이 만들어야 한다.  
하지만 배부용 최종본에는 품질이 검수된 문항만 남긴다.

원칙:

- 초안은 많이 만든다.
- 선지 품질 필터로 과감히 제거한다.
- 품질이 낮은 문항을 억지로 살리지 않는다.
- 문항 수가 줄어도 배부용 신뢰도를 우선한다.

### 1.4 한 지문당 1~3문항

한 지문에서 무조건 3문항을 뽑지 않는다.

- 1문항: 핵심 포인트가 하나인 지문
- 2문항: 내용 이해 + 어법/어휘가 가능한 지문
- 3문항: 구조가 풍부하고 변형 여지가 큰 지문

같은 원천 지문을 여러 버전으로 나눠 문제 수를 늘린다.

예:

```text
원문 버전: 내용일치
어휘 변형 버전: 빈칸
구문 변형 버전: 어법
전체 변형 버전: 주제문 서술형
```

### 1.5 선지는 시험지 품질의 핵심이다

선지가 이상하면 문제 전체가 무너진다.

제거 대상:

- 범용 패딩 선지
- 메타 선지
- 깨진 문자
- 길이 불균형
- 너무 뻔한 오답
- 정답만 비정상적으로 길거나 구체적인 선지
- 본문과 연결되지 않는 허무맹랑한 선지

## 2. 연구 기반 설계 원리

이 장은 교육평가·문항개발 관점을 Ray's Drill 제작 규칙으로 번역한 것이다.  
학생용 문제에는 이론 용어를 드러내지 않고, 제작자용 내부 기준으로만 사용한다.

### 2.1 평가 타당도 원리

좋은 문항은 “풀기 어려운 문항”이 아니라, “측정하려는 능력을 정확히 측정하는 문항”이다.

Ray's Drill의 타당도 기준:

- 주제 문항은 지문 전체의 중심 논지를 측정해야 한다.
- 일치/불일치 문항은 세부 정보 확인 능력을 측정해야 한다.
- 빈칸 문항은 앞뒤 논리와 핵심 개념 복원 능력을 측정해야 한다.
- 문장삽입 문항은 응집성, 지시어, 연결어, 전후 문맥 판단을 측정해야 한다.
- 어법 문항은 문장 구조와 문맥 속 언어형식 판단을 측정해야 한다.
- 서술형 문항은 학생이 실제로 구성해 낼 수 있는 표현 능력을 측정해야 한다.

타당도가 낮은 문항:

- 정답을 암기 여부로만 맞힐 수 있음
- 선지 제거 요령으로만 풀림
- 배경지식 없이는 풀기 어려움
- 발문과 실제 측정 능력이 다름
- 오답이 너무 허술해서 변별이 안 됨

### 2.2 증거 중심 설계

문항을 만들기 전에 먼저 다음을 정해야 한다.

1. 이 문항이 측정하려는 능력은 무엇인가
2. 학생의 어떤 반응이 그 능력의 증거가 되는가
3. 그 반응을 끌어내기 위해 어떤 지문 조작과 발문이 필요한가

문항 카드에는 반드시 다음 필드가 있어야 한다.

```text
측정능력:
정답 근거:
오답 논리:
필요 지문 조작:
학생 반응:
해설 포인트:
```

예:

```text
측정능력: 대조 이후 결론을 파악하는 능력
정답 근거: however 뒤 문장이 앞의 일반 믿음을 반박함
오답 논리: 앞부분의 일반 믿음을 결론으로 오해
필요 지문 조작: 결론 표현을 빈칸 처리
학생 반응: 대조 관계를 읽고 결론을 복원
해설 포인트: however 이전 정보는 배경, 이후 정보가 필자 주장
```

### 2.3 인지 부하 조절

학생이 어려워해야 하는 부분은 “영어 지문 이해”이지, 불친절한 문제 형식이 아니다.

문항 난이도를 올리는 바른 방법:

- 추론 단계 추가
- 오답 매력도 상승
- 지문 변형 강도 상승
- 근거 문장 간 거리 증가
- 대조/인과/예시 구조 복합화

문항 난이도를 올리는 나쁜 방법:

- 힌트 제거
- 선지 모호화
- 발문 불명확화
- 서술형 단어 수 부정확
- 지나치게 긴 답안 요구
- 고1 범위를 넘는 문법 함정

### 2.4 기능적 오답 원리

오답은 단순히 틀린 문장이 아니라, 학생의 오개념을 드러내야 한다.

기능적 오답은 다음 역할을 한다.

- 학생이 어디서 오독했는지 보여준다.
- 상위권과 중위권을 구분한다.
- 해설에서 학습 포인트를 제공한다.
- 정답을 더 분명하게 만든다.

비기능적 오답:

- 아무도 고르지 않을 오답
- 본문과 무관한 오답
- 문법적으로 이상한 오답
- 정답 반대말만 붙인 오답

### 2.5 구성 균형 원리

문제은행은 무작위처럼 보여도 내부적으로 균형이 있어야 한다.

조정 대상:

- 출처 분포
- 유형 분포
- 변형 강도
- 정답 번호
- 난이도
- 객관식/서술형 비율
- 내용 이해/어법/간접쓰기 비율

## 3. Ray's Drill 5층 출제 모델

Ray's Drill은 다음 5층 구조로 만든다.

```text
1층 원천 지문 보존
2층 지문 변형
3층 문항 조작
4층 선지/서술형 조건 설계
5층 시험지 조립과 해설
```

### 3.1 1층: 원천 지문 보존

원천 지문을 정확히 확보한다.

필수 작업:

- 출처 기록
- 지문 ID 부여
- Gateway 제외 여부 표시
- 대화문 포함 여부 표시
- 원문 전체 보존
- 줄바꿈·기호 정리

출처 메타 예시:

```json
{
  "source_id": "SL04_EX01",
  "source_name": "수특라이트 04강 Exercise 01",
  "include": true,
  "gateway": false,
  "text_type": "expository",
  "dialogue": false
}
```

### 3.2 2층: 지문 변형

지문 변형은 네 단계로 관리한다.

| 단계 | 이름 | 설명 | 권장 유형 |
|---|---|---|---|
| T0 | 원문 | 원문 그대로 | 내용일치, 주제, 제목 |
| T1 | 어휘 변형 | 핵심어 치환 | 빈칸, 어휘, 요약 |
| T2 | 구문 변형 | 구조 전환 | 어법, 삽입, 순서 |
| T3 | 전체 변형 | 주제 동일 재작성 | 주제문 서술형, 고난도 빈칸 |

### 3.3 3층: 문항 조작

유형별 조작은 지문 안에 들어가야 한다.

| 유형 | 조작 |
|---|---|
| 빈칸 | 정답 구간을 실제 빈칸 처리 |
| 삽입 | 삽입 문장을 제거하고 위치 표시 |
| 순서 | 문장/문단 블록 재배열 |
| 어법 | 오류 또는 선택 지점 표시 |
| 어휘 | 문맥상 낱말 표시 |
| 어색한 문장 | 흐름을 깨는 문장 삽입 |
| 요약 | 별도 요약문에 빈칸 생성 |

### 3.4 4층: 선지/서술형 조건 설계

객관식은 정답 하나와 기능적 오답 네 개를 만든다.  
서술형은 모범답안을 먼저 만들고 조건을 역산한다.

객관식:

```text
정답 - 본문 논리와 완전 일치
오답1 - 부분 참/전체 거짓
오답2 - 인과 뒤집기
오답3 - 범위 과잉 일반화
오답4 - 세부정보 혼동
```

서술형:

```text
모범답안 작성
단어 수 계산
필수 단어 선정
힌트 강도 결정
채점 기준 작성
```

### 3.5 5층: 시험지 조립과 해설

문항은 시험지로 조립될 때 다시 품질이 달라진다.

조립 시 확인:

- 같은 출처 연속 회피
- 같은 유형 연속 회피
- 같은 정답 번호 연속 회피
- 지문 길이와 페이지 흐름 조정
- 서술형 답안란 중복 제거
- 지문과 선지 사이 여백 확보

## 4. 유형별 계승발전 설계

### 4.1 주제·요지·제목

기존 원칙:

- 글 전체를 포괄해야 한다.
- 사례 하나를 정답으로 만들면 안 된다.

계승발전:

- 선지를 모두 비슷한 추상도에 맞춘다.
- 정답만 유독 “사회, 영향, 중요성” 같은 큰 단어를 다 포함하게 만들지 않는다.
- 오답은 모두 본문 속 소재를 품고 있어야 한다.

제작 프롬프트:

```text
다음 지문을 읽고 주제/요지/제목 문항을 만든다.
정답은 글 전체의 결론을 포괄하게 만들고,
오답 4개는 각각 사례 일반화, 원인-결과 전도, 범위 과잉, 초점 이동으로 설계한다.
다섯 선지의 길이와 추상도를 비슷하게 맞춘다.
학생용 선지에 '본문은', '글은' 같은 메타 표현을 쓰지 않는다.
```

검수 질문:

- 정답이 사례가 아니라 결론인가
- 오답도 지문과 연결되어 있는가
- 정답만 너무 길거나 추상적인가
- 선지 하나가 너무 쉽게 제거되는가

### 4.2 빈칸

기존 원칙:

- 빈칸은 핵심 논리 지점에 둔다.
- 앞뒤 문맥으로 풀 수 있어야 한다.

계승발전:

- 빈칸은 단어 암기가 아니라 논리 복원이어야 한다.
- 오답은 모두 품사와 문법상 들어갈 수 있어야 한다.
- 정답은 앞뒤 맥락을 모두 만족해야 한다.

빈칸 위치 등급:

| 등급 | 위치 | 품질 |
|---|---|---|
| A | 결론 핵심어 | 좋음 |
| A | 대조 이후 반전 표현 | 좋음 |
| B | 인과 결과 | 사용 가능 |
| B | 요약 표현 | 사용 가능 |
| C | 단순 명사 | 약함 |
| D | 고유명사/수치 | 금지 |

제작 프롬프트:

```text
빈칸은 지문의 결론, 대조, 인과, 일반화 지점 중 하나에 둔다.
정답은 앞문장과 뒷문장을 모두 만족해야 한다.
오답은 품사와 표면 문법은 맞지만 논리 방향, 범위, 초점이 어긋나게 만든다.
정답 단어가 지문 다른 부분에 그대로 반복되어 노출되지 않는지 확인한다.
```

### 4.3 문장삽입

기존 원칙:

- 삽입 문장은 지문에서 실제로 제거한다.

계승발전:

- 삽입 문장은 “앞 문장을 받아야 하고, 뒤 문장을 열어야” 한다.
- 위치 후보는 모두 어느 정도 그럴듯해야 한다.
- 정답 근거는 지시어, 연결어, 반복어, 정보 순서 중 최소 2개 이상이어야 한다.

좋은 삽입 문장 조건:

- 대명사 또는 지시어가 있음
- 연결어가 있음
- 앞 정보의 재진술 또는 확장
- 뒤 문장의 예시/결론을 준비

제작 프롬프트:

```text
원문에서 응집성이 강한 문장 하나를 제거한다.
남은 지문에 (A)~(E)를 넣는다.
주어진 문장의 지시어, 연결어, 반복어, 정보 순서를 근거로 정답 위치를 정한다.
오답 위치는 앞뒤 한쪽만 그럴듯하게 설계한다.
제거한 문장이 공통 지문 안에 그대로 남아 있지 않은지 반드시 확인한다.
```

### 4.4 글의 순서

기존 원칙:

- 문단/문장 블록을 실제로 분리한다.

계승발전:

- 블록마다 담화 기능을 부여한다.
- 순서는 키워드 매칭이 아니라 기능 연결로 풀리게 한다.

블록 기능 예시:

```text
도입 - 문제 제기
전개 - 원인 설명
사례 - 구체화
반전 - 기존 생각 반박
결론 - 일반화
```

제작 프롬프트:

```text
지문을 기능 단위로 3개 블록으로 나눈다.
각 블록의 첫 문장과 마지막 문장이 앞뒤 연결 단서를 갖도록 유지한다.
정답 순서 외의 오답 순서는 연결어, 대명사, 예시-일반화 순서 중 하나가 깨지게 만든다.
```

### 4.5 어색한 문장

계승발전:

- 삽입 문장은 소재가 완전히 동떨어지면 안 된다.
- 같은 소재권 안에 있지만 논리 기능이 어긋나야 한다.

좋은 어색한 문장:

```text
지문이 사회적 조건이 취향을 형성한다고 설명하는데,
중간에 개인 취향이 완전히 유전적으로 결정된다는 문장을 넣는다.
소재는 취향이지만 논리 방향이 어긋난다.
```

검수 질문:

- 정답 문장이 너무 노골적으로 튀는가
- 주변 문장과 연결어가 맞지 않는가
- 다른 문장도 어색하다고 볼 여지가 있는가

### 4.6 일치/불일치

계승발전:

- 세부정보를 베끼는 것이 아니라 정보 관계를 비튼다.
- 오답은 본문 특정 근거와 대조 가능해야 한다.

변형 방식:

- 시점 바꾸기
- 수량 바꾸기
- 주체 바꾸기
- 원인/결과 바꾸기
- 조건 누락
- 정도 표현 바꾸기
- 예외를 일반화

제작 프롬프트:

```text
선지 5개 모두 본문 근거 위치를 갖게 만든다.
오답은 본문에 없는 내용을 무작위로 추가하지 말고,
본문의 주체, 조건, 원인, 결과, 정도 중 하나를 바꾸어 만든다.
정답/오답 선지의 정보량을 비슷하게 맞춘다.
```

### 4.7 어법

계승발전:

- 단순 문법 함정이 아니라 지문 속 문장 구조 이해를 묻는다.
- 고1 수준에서 설명 가능한 포인트를 우선한다.

권장 포인트:

- 수일치
- 시제
- 태
- 관계사
- 분사
- 준동사
- 병렬
- 접속사/전치사
- 비교
- 명사절

금지:

- 원어민도 판단이 갈릴 표현
- 지나치게 학술적인 문법 명칭이 필요한 문제
- 의미상 둘 다 가능한 선택지
- 지문 맥락과 무관한 문법 퍼즐

### 4.8 서술형

계승발전의 핵심:

- 서술형은 주제문, 내용이해, 어법 교정 중심으로 간다.
- 구문변환만 시키는 문제는 줄인다.
- 조건부 영작은 학생이 실제로 쓸 수 있게 힌트를 조절한다.

서술형 힌트 사다리:

| 단계 | 제공 정보 | 사용 상황 |
|---|---|---|
| H0 | 힌트 거의 없음 | 매우 쉬운 단답 |
| H1 | 한국어 뜻 | 기본 영작 |
| H2 | 한국어 뜻 + 필수어 | 표준 조건부 영작 |
| H3 | 한국어 뜻 + 필수어 + 단어 수 | 일반 내신형 |
| H4 | H3 + 첫 단어 | 문장 구조가 어려움 |
| H5 | H3 + 주어/시작구 | 첫 단어만으로 불가능 |

기본 규칙:

- 한국어 뜻을 안 주면 힌트를 더 많이 준다.
- 한국어 뜻을 주면 단어 힌트를 조금 줄일 수 있다.
- 조건 단어가 주어와 겹치면 다른 단어를 힌트로 준다.
- 정답을 먼저 만든 뒤 단어 수를 계산한다.

어법 교정 서술형:

```text
다음 글에서 어법상 틀린 곳 7개 중 4개를 찾아 바르게 고쳐 쓰시오.
```

이 유형은 학생 부담을 조절하면서도 어법 변별력이 높다.  
단, 오류 7개는 모두 고1 수준에서 설명 가능해야 한다.

## 5. 선지 제작 계승발전

### 5.1 선지 설계 6단계

```text
1. 정답을 먼저 쓴다.
2. 정답 근거 문장을 지정한다.
3. 오답의 오독 유형을 배정한다.
4. 오답을 본문 키워드와 연결한다.
5. 선지 길이와 문체를 맞춘다.
6. 정답번호를 재배치한다.
```

### 5.2 오답 DNA

각 오답은 반드시 오답 DNA를 가져야 한다.

| 오답 DNA | 설명 |
|---|---|
| 부분참 | 일부 정보는 맞지만 결론이 틀림 |
| 전도 | 원인과 결과, 전제와 결론이 뒤집힘 |
| 과잉 | 제한된 주장을 절대화 |
| 축소 | 글 전체를 일부 사례로 축소 |
| 초점이동 | 핵심 논점이 주변 소재로 이동 |
| 태도왜곡 | 필자 태도나 강도 왜곡 |
| 조건누락 | 중요한 조건을 빼고 일반화 |
| 지시혼동 | 대명사/지시어의 대상 혼동 |

### 5.3 선지 길이 균형

선지 길이가 답의 단서가 되면 안 된다.

권장:

- 주제/요지: 12~22어절 안에서 균형
- 제목: 4~10어절 안에서 균형
- 일치/불일치: 정보 단위 수를 비슷하게
- 빈칸: 품사와 구조를 동일하게
- 어법: 문항 구조상 자연스러움 우선

### 5.4 제거해야 할 선지 패턴

자동 필터에 넣을 패턴:

```text
본문은
글은
사전적
문자적
원문보다
근거 없이
글 밖
전체 결론이 충분히
undefined
NaN
...
…
```

수동 검수에서 제거할 패턴:

- 한국어가 부자연스러운 선지
- 정답만 과도하게 구체적인 선지
- 오답이 너무 코미디처럼 틀린 선지
- 선지 사이 범주가 겹치는 경우
- 두 개 이상 정답으로 방어 가능한 경우

### 5.5 선지 정비 프롬프트

```text
다음 문항의 선지를 전수 정비한다.

정비 기준:
1. 정답은 하나만 가능해야 한다.
2. 오답 4개는 모두 본문 일부와 연결되는 매력적 오답이어야 한다.
3. 다섯 선지의 길이와 문체를 맞춘다.
4. '본문은', '글은', '사전적', '문자적', '원문보다' 같은 메타 표현을 제거한다.
5. 오답마다 부분참, 전도, 과잉, 축소, 초점이동, 태도왜곡, 조건누락 중 하나의 논리를 부여한다.
6. 정답만 유독 구체적이거나 길면 선지를 다시 쓴다.

출력:
- 정비된 선지 5개
- 정답
- 오답별 오답 논리
- 정답 근거
```

## 6. 난이도 설계

### 6.1 난이도는 세 층으로 본다

문항 난이도는 단순히 “어려운 단어가 많다”가 아니다.

| 층 | 요소 |
|---|---|
| 지문 난이도 | 어휘, 구문, 추상도, 배경지식 |
| 문항 난이도 | 추론 단계, 근거 거리, 유형 복잡도 |
| 선지 난이도 | 오답 매력도, 길이 균형, 미세한 의미 차이 |

### 6.2 고1 표준 난이도

고1 표준 난이도는 다음 범위를 말한다.

- 낯선 어휘가 있어도 문맥으로 추론 가능
- 문장 길이는 길 수 있으나 구조 분석 가능
- 어법 포인트는 학교 문법에서 설명 가능
- 서술형은 조건과 힌트가 충분함
- 배경지식 없이 지문 안 근거로 해결 가능

### 6.3 변별 문항

변별 문항은 일부 포함한다.

좋은 변별:

- 대조/양보 뒤 결론 파악
- 사례와 주장 구분
- 요약문에서 핵심어 두 개 복원
- 매력적 오답 사이에서 최선 선택
- 어법 오류 여러 개 중 일부 수정

나쁜 변별:

- 단어를 몰라서 못 품
- 조건이 불친절해서 못 씀
- 정답 근거가 애매함
- 지문 밖 지식이 필요함

## 7. 해설지 계승발전

### 7.1 해설지는 두 겹으로 만든다

1차 해설: 왜 정답인가  
2차 해설: 왜 오답에 끌리는가

문항별 해설 구조:

```text
정답
출제의도
정답 근거
오답 분석
지문 해석
핵심 어휘
주요 구문
키포인트
배경지식
```

### 7.2 오답 분석의 질

나쁜 오답 해설:

```text
본문과 다르므로 오답이다.
```

좋은 오답 해설:

```text
②는 본문 앞부분의 사례와는 연결되지만, 필자가 결론에서 말하는
사회적 조건과 미적 경험의 관계를 개인의 자유 선택 문제로 바꾸고 있어 오답이다.
```

### 7.3 배경지식 중복 제거

같은 개념이 여러 번 나오면 처음에만 자세히 설명한다.

예:

- Pierre Bourdieu: 처음 등장 문항에서만 상세 설명
- capital: 사회적/문화적 자본 개념은 처음만 상세 설명
- distinction: 반복 시 간단히 “앞 문항 참조” 수준

### 7.4 어휘 정리 방식

단어 뜻만 쓰지 않는다.

형식:

```text
determination n. 규정 요인, 결정 요인
- 문맥상 의미: 개인의 취향과 경험을 형성하는 사회적 조건
- 주의: determination을 '결심'으로 해석하면 문맥이 어긋남
- 출제 포인트: social determinations = 사회적 규정 요인
```

### 7.5 구문 정리 방식

형식:

```text
문장:
The analysis of this relation must go back to the earliest stage of a child's life.

구조:
주어 The analysis of this relation
동사 must go back
전치사구 to the earliest stage...

해석:
이 관계에 대한 분석은 아이의 삶의 가장 초기 단계로 거슬러 올라가야 한다.

출제 포인트:
must go back to는 물리적 이동이 아니라 분석의 출발점을 뜻한다.
```

## 8. 시험지 조립 연구판

### 8.1 실제 시험지처럼 보이는 조건

시험지는 내용뿐 아니라 시각적 신뢰가 중요하다.

필수:

- DOCX 제공
- 2단 조판
- 문제 사이 여백
- 선지 줄 간격 확보
- 서술형 답안란 적정 크기
- 불필요한 글머리표 제거
- 지문 잘림 없음
- 문항 번호 명확

### 8.2 문항 배치 규칙

문제은행 배치:

- 유형을 완전히 묶지 않고 적절히 섞는다.
- 같은 지문 출처가 연속되지 않게 한다.
- 쉬운 문항과 어려운 문항을 리듬감 있게 섞는다.
- 서술형은 너무 몰아서 배치하지 않는다.

동형모고 26문항 배치:

```text
1~5: 내용 이해/주제/요지
6~10: 일치/불일치/어휘
11~15: 빈칸/삽입/순서
16~20: 어법/어색한 문장/요약
21~26: 서술형/복합형/고난도 변별
```

단, 실제 조립에서는 지문 길이와 페이지 흐름을 고려해 조정한다.

### 8.3 정답번호 분포

객관식 정답은 균등 분포가 기본이다.

기준:

- ①~⑤ 각 번호가 비슷하게 등장
- 같은 번호 3연속 금지
- 같은 유형에서 같은 번호 반복 금지
- 어려운 문항의 정답이 뒤 번호에 몰리지 않게 함

## 9. 하네스 확장 규격

### 9.1 자동 검수 게이트

문제은행 생성 후 다음 게이트를 통과해야 한다.

| 게이트 | 이름 | 검사 |
|---|---|---|
| G1 | Source Gate | 출처, 범위, 제외 지문 확인 |
| G2 | Passage Gate | 지문 축약, 중략, 누락 확인 |
| G3 | Operation Gate | 빈칸/삽입/어법 조작 반영 확인 |
| G4 | Choice Gate | 선지 품질 패턴 제거 |
| G5 | Answer Gate | 정답 하나, 번호 분포 확인 |
| G6 | CR Gate | 서술형 단어 수, 힌트, 모범답안 확인 |
| G7 | Layout Gate | DOCX 열림, 2단, 글머리표, 잘림 확인 |
| G8 | Explanation Gate | 해설 구성 요소 확인 |

### 9.2 품질 점수

각 문항에 품질 점수를 부여한다.

```text
지문 적합도: 0~2
유형 적합도: 0~2
선지 품질: 0~3
정답 근거: 0~2
해설 품질: 0~2
조판 안정성: 0~1
총점: 12점
```

배부 기준:

- 10~12점: 배부 가능
- 8~9점: 수정 후 사용
- 7점 이하: 제외 또는 재작성

### 9.3 선지 자동 검사 의사코드

```text
for item in item_bank:
    if item.type is objective:
        assert len(item.choices) == 5

        reject_if_choice_length_gap_too_large(item.choices)
        reject_if_answer_is_only_specific_choice(item.choices, item.answer)
        reject_if_any_choice_is_grammatically_broken(item.choices)
```

for item in constructed_response_items:

Codex:

- 최종 통합

Claude:

- 문항 초안 대량 생성

- 문항 감수
- 자연스러운 한국어 표현 점검
- 자료 해석 보조

### 10.2 상호 검수 방식

Claude가 만든 문항을 Codex가 볼 때:

- 공통 지문 조작이 반영되었는가
- 선지가 범용 패딩이 아닌가
- 서술형 조건이 충분한가
- 정답이 하나인가
- 지문을 줄이지 않았는가

Codex가 만든 문항을 Claude가 볼 때:

- 한국어 발문이 자연스러운가
- 오답이 실제 학생에게 매력적인가
- 해설이 납득 가능한가
- 난이도가 과도하지 않은가

## 11. 제작자용 프롬프트 모음

### 11.1 지문 분석 프롬프트

```text
다음 영어 지문을 문제은행 출제용으로 분석하라.

출력 항목:
1. 핵심 주제
2. 필자의 주장 또는 결론
3. 논리 구조
4. 주요 어휘
5. 주요 구문
6. 어법 출제 포인트
7. 빈칸 가능 지점
8. 문장삽입 가능 문장
9. 순서 배열 가능 블록
10. 서술형 가능 문장

주의:
- 지문을 줄이지 말 것
- 배경지식은 정답 판단에 필요하지 않은 수준으로만 설명할 것
```

### 11.2 문항 생성 프롬프트

```text
다음 지문으로 내신형 문제은행 문항을 생성하라.

조건:
1. 한 지문당 1~3문항만 만든다.
2. 유형은 내용이해, 어법, 빈칸, 삽입, 순서, 서술형 중 지문에 맞는 것만 선택한다.
3. 삽입/빈칸/어법/어색한 문장은 공통 지문 안에 조작을 반영한다.
4. 문제용 별도 지문을 따로 주지 않는다.
5. 선지는 모두 매력적 오답으로 만든다.
6. 서술형은 모범답안을 먼저 만들고 단어 수를 정확히 계산한다.
```

### 11.3 서술형 하향 조정 프롬프트

```text
다음 서술형 문항이 고1 학생이 실제로 쓸 수 있는지 검수하라.

검수 기준:
1. 한국어 뜻이 있는가
2. 단어 수가 정확한가
3. 필수 단어가 충분한가
4. 첫 단어만으로 부족하면 주어를 주었는가
5. 조건 단어가 주어와 겹치면 다른 힌트를 주었는가
6. 모범답안이 자연스러운가
7. 허용 답안 범위가 있는가

부족하면 힌트를 보강한 새 문항으로 재작성하라.
```

### 11.4 최종 전수검사 프롬프트

```text
다음 문제은행을 전수검사하라.

검사:
1. 이상한 선지
2. 정답 두 개 가능성
3. 지문 중복 제공
4. 삽입/빈칸 조작 미반영
5. 지문 축약/중략
6. 서술형 힌트 부족
7. 단어 수 오류
8. 해설 누락
9. 조판상 가독성 문제

출력:
- 삭제할 문항
- 수정할 문항
- 그대로 사용할 문항
- 최종 배부 가능 문항 수
```

## 13. 연구 근거 요약

이 문서는 다음 자료의 방향을 제작 규칙으로 번역했다.

### 13.1 학생평가와 평가도구 개발

학생평가지원포털은 성취기준, 평가도구 개발, 서·논술형 평가 도구, 채점기준 자료를 체계적으로 제공한다.  
Ray's Drill은 이를 반영해 문항을 단순 유형별로만 만들지 않고, 측정 능력과 채점 기준을 함께 설계한다.

### 13.2 고등학교 학생평가 자료

고등학교 학생평가 자료는 평가 계획에 맞는 문항·과제·채점기준 개발과 예시 답안의 중요성을 강조한다.  
Ray's Drill의 서술형은 이 원리를 반영해 모범답안을 먼저 만들고, 단어 수와 힌트를 역산한다.

### 13.3 영어과 선택형 문항 제작 자료

영어과 선택형 문항 제작 자료는 영어 문항 개발의 실제 절차와 검토 관점을 제공한다.  
Ray's Drill은 이를 계승해 중심 내용, 세부 정보, 맥락, 언어형식·어휘, 간접쓰기 유형을 문제은행 축으로 삼는다.

### 13.4 선다형 문항 개발 원리

선다형 문항은 하나의 명확한 정답과 기능적 오답이 있어야 한다.  
Ray's Drill은 정답 하나, 매력적 오답 네 개, 오답 DNA, 정답번호 균형을 필수 조건으로 둔다.

### 13.5 오답 분석과 기능적 오답

오답은 단순 장식이 아니라 학생 이해 수준을 드러내는 장치다.  
Ray's Drill은 오답을 부분참, 전도, 과잉, 축소, 초점이동, 태도왜곡, 조건누락 등으로 분류해 설계한다.
