# 산출물 형식 규격 (Output Format Spec) — 로직화

생성 2026-07-10 · 원칙: **산출물마다 고유 판형이 있다.** 같은 문항 데이터라도 문제지/동형모고/워크북/분석지는 서로 다른 형식 요건을 충족해야 한다. 파이프라인 `selfllm/suite_harness.js`(한 지문→전 산출물), 하네스 `selfllm/format_audit.js`(형식 전수검사).

## F1. 분석지 (Analysis Sheet) — 학습자료 판형
| 요건 | 규격 |
|---|---|
| 한눈 요약 | 주제 TOPIC·필자주장 THESIS 박스가 최상단 + 글의 흐름(문장별 역할) 화살표 |
| 본문 성분 분석 | **전 문장** S/V/O/C/M 청크(어구 밑 라벨), 문장마다 직역·구문·✎출제활용 병기 |
| 출제 지도 | 유형×빈출위치×변환방법 표(변형문제 제작기 로직 기반, 실제 생성 예시 인용) |
| 어휘 | 어휘·구문·연결어 2단 압축 |
| 금지 | 별도 문장분석 섹션 중복, LLM 추측성 출제예상(실제 metadata 우선) |

## F2. 문제지 (Question Paper) — 내신 시험지 판형
| 요건 | 규격 |
|---|---|
| 헤더 | 과목·세트명 + 이름/학번/점수 기입란 |
| 공통지문 | 1회 게시, 무표식 문항은 "▲ 위 지문 참조", 표식 문항은 자기 지문(밑줄·번호) 표시 |
| 문항 | 유형 라벨 표시(교사용 식별), 배점 [3점] 표기, 서술형 기입선 |
| 해설 | 본문과 분리(토글/별면), 오답 진단·처방(Rx) 포함 |

## F3. 동형 모의고사 (Mock) — 수능 실전 판형
| 요건 | 규격 |
|---|---|
| 헤더 | "제3교시 영어 영역" 스타일 + 제한시간·총점 |
| **수능 번호 매핑** | 필자주장→20 · 함의→21 · 요지→22 · 주제→23 · 제목→24 · 내용일치→26 · 어법→29 · 어휘→30 · 빈칸→31 · 무관→35 · 순서→36 · 삽입→38 · 요약→40 (수능 번호 순 정렬) |
| 문항 독립 | 각 문항이 **자기 지문 전문**을 포함(수능 판형 — 공통지문 참조 금지) |
| 라벨 은닉 | 유형명 미표기(수능엔 없음), [3점]만 표기 |
| 서답형 | 수능 외 유형(서술형·어법수정·전체배열)은 뒤에 '서답형 1·2·3' 섹션 |
| 정답표 | 마지막 면 — 번호별 정답 일람 |

## F4. 워크북 (Process Workbook) — 스캐폴드 판형
| 요건 | 규격 |
|---|---|
| 단계 | 전 문항 `_work.steps`(어법·어휘 5단계: 관찰→분류→판정→근거→메타, 그 외 3단계) |
| 학생용 | reveal 숨김·기입선 노출, 각 단계 ask+show+input |
| 교사용 | reveal(answer·why·source) 표시 |
| 정합 | reveal 정답번호 == q.answer (desync 0) |

## 파이프라인
```
지문 1개 → analysisSheet(성분 9/9·출제플로) ─┐
         → generateExam(전 유형, 키가드·정답분산·Rx·stampWork) ─┴→ suite.json
suite.json → 렌더러(F1~F4 각자 판형) → 분석지·문제지·동형모고·워크북 + 정답해설
suite.json → format_audit(형식 전수검사) → 합격 후 납품
```

## 하네스(format_audit) 검사 항목
- F1: topic·thesis·성분(전 문장 [SVOCM] 형식)·examFlow 존재
- F2: 전 문항 발문·선지/기입선, Rx 부착률
- F3: 수능 번호 매핑 가능 문항 수, [3점] 문항 존재, 서답형 분리 목록, 정답표 데이터
- F4: 전 문항 _work.steps, 어법·어휘 5단계, reveal==answer 정합
