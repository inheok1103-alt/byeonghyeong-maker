학생을 선택하면 학습 기록이 여기에 표시됩니다.

⚙ 아카이브 설정 안내 (1회)
  1. Notion → Settings → Connections → Develop or manage integrations → New integration(Internal) 생성 → secret_... 토큰 복사
  2. Ray English 학생 아카이브 페이지 우상단 ⋯ → Connections → (통합 이름)으로 공유
  3. Cloudflare 대시보드 → Workers → ray-proxy → Settings → Variables → Add secret: 이름 NOTION_TOKEN, 값 = 토큰 → 저장 후 Deploy
  4. 이 페이지 새로고침 → 아카이브가 활성화됩니다.

토큰은 CF 워커 시크릿에만 저장됩니다(브라우저·공개코드에 절대 안 들어감). DB ID는 코드에 있으나 토큰 없이는 접근 불가.
